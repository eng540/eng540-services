# دليل المخططات الهندسية (حزمة الرخص) — المرجع الفني المشترك

> إصدار 0.1 · 2026-11-10 · يُربط إليه من ملفات الخدمات (1، 5، 6، 9، 10).

## 1. حزمة مخططات رخصة البناء النمطية 📚

| المخطط | محتواه | غرضه في الاعتماد |
|---|---|---|
| المخطط العام (Site Plan) | موقع القطعة، حدودها، الارتدادات، مواقع البناء والساحات، الاتجاهات | مطابقة الاشتراطات البلدية والارتدادات |
| المساقط الأفقية (Floor Plans) | كل دور بالأبعاد والغرف والجدران | التحقق من نسب البناء والمساحات والاستخدامات |
| المساقط الرأسية (Elevations) | الواجهات الأربع بالارتفاعات | حدود الارتفاعات والمناسيب وشكلية الواجهات |
| المقاطع (Sections) | مقطع يوضح الأدوار والارتفاعات والعزل | فحص التوافق الإنشائي والارتفاع |
| التفاصيل الإنشائية (Details) | الأساسات، الأعمدة، الروافد، العزل | المطابقة لكود البناء السعودي |
| الجداول (Schedules) | جدول المساحات، الأبواب والشبابيك، التشطيبات | التحقق الحسابي (نسبة البناء، المواقف…) |
| مخطط الموقع/البنية التحتية | توصيلات، ميول، تصريف | اشتراطات البنية التحتية |

> ✅ [متحقق — بلدي]: الطلب في بلدي يتضمن «التصاميم الهندسية المعمارية والإنشائية» ومراجعتها مطابقةً «اشتراطات كود البناء السعودي» — أي أن الحزمة أعلاه تُعد وفق SBC + اشتراطات البلدية معاً.

## 2. سلسلة إعداد المخطط (من الفكرة للاعتماد)

1. جمع المدخلات: صك محدث، قرار مساحي، اشتراطات القطعة، دراسة التربة.
2. مخطط أولي (Concept): موازنة الأشتراطات مع رغبة المالك — **نقطة القرار الأهم**: أية رغبة تخالف الاشتراطات تُحسم هنا قبل الإنفاق على التصميم الكامل.
3. التصميم الكامل (معماري ثم إنشائي ثم تفاصيل) بمراجعة داخلية بالمكتب.
4. التوقيعات المهنية (مهندس مصنف سارٍ) + إقرارات المكتب.
5. الرفع في بلدي أعمال ← فحص الفاحص الفني ← اعتماد الأمانة (شهادة اعتماد التصاميم ✅).
6. الأرشفة: نسخة معتمدة + كل المراسلات.

## 3. معايير جودة الحزمة (قبل الرفع) — قائمة تحقق المكتب

- [ ] الأبعاد في المخططات تطابق القرار المساحي/الرفع (لا تخمين).
- [ ] الارتدادات والنسب والارتفاعات ضمن اشتراطات القطعة المحددة (وليس «أشتراطات جار»).
- [ ] جدول المساحات متوافق حسابياً مع المساقط (فارق مساحات = ملاحظة شبه مؤكدة).
- [ ] المواقف مطابقة لاشتراطات (عدد/أبعاد).
- [ ] التفاصيل الإنشائية مطابقة SBC.
- [ ] التوقيعات والاعتمادات مكتملة وسارية.

## 4. الأخطاء المكلفة الأكثر تكراراً 💼

1. تصميم على اشتراطات قطعة مجاورة (تمييز/عرض شارع مختلف).
2. حساب نسبة البناء على مساحة الصك وليس المساحة الاعتمادية.
3. تجاهل منسوب الشارع في المناسيب.
4. مخططات غير متسقة داخلياً (مسقط ≠ جدول).
5. توقيع منتهي التصنيف.
