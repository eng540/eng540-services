# الخدمة 11 — الجانب الفني، الحجز الميداني، والرسوم والتسعير

> إصدار 1.0 · 2026-11-10

## 1. سلسلة الأعمال الفنية

| العمل | أداته | منفّذه | ناتجه |
|---|---|---|---|
| رفع واقعي موثق | GNSS/Total Station + مقياس ليزر | مساح مرخص 💼 | تقرير رفع |
| مخططات «كما هو» | أوتوكاد | مصمم مكتب 💼 | ملفات DWG/PDF ⚠️ |
| تقييم إنشائي عابر (مؤشرات خطر) | فحص بصري + مطرقة/عداد عند الحاجة 📚 | مهندس إنشائي 💼 | إشارة «يحتاج فحصاً معززاً» |
| توثيق صوري قبل/بعد | كاميرا مؤرخة + زوايا موحدة | موقع | أرشيف إثبات |
| تصميم المعالجة | اشتراطات القطعة ⚠️ + كود البناء | مصمم مكتب 💼 | مخطط معالجة |
| تنفيذ الإزالة | معدات هدم صغيرة | مقاول مصنف 💼 | إنجاز حرفي للقرار |

**حدود الأدوار (غير قابلة للمساومة):** القياس للمساح — الرسم لمصمم المكتب — الحساب الإنشائي للمهندس — التنفيذ للمقاول — المنسق لا يقيس ولا يرسم.

## 2. الحجز الميداني والتنسيق

| الزيارة | كيف تُرتب | ماذا تحضر |
|---|---|---|
| توثيق أولى | حجز مع العميل 💼 | كاميرا + جدول توثيق |
| رفع مساحي | اتفاق وصول مع الجيران مسبقاً 💼 | أدوات المساح |
| معاينة بلدية ⚠️ | غالباً «تقفز للتنفيذ» — كن حاضراً دائماً أو فوّض مستضيفاً 💼 | الملف + صور قبل |
| تنفيذ الإزالة | جدولة مع المقاول + قطع مرافق 🔴 أولاً | تصاريح الهدم ✅ |
| توثيق بعدي | مباشرة بعد الإنجاز | نفس زوايا الصور «قبل» |

**قاعدة الحضور:** كل زيارة بلدية لمبنى فيه مخالفة = حدث قانوني محتمل؛ غيابك يُفسَّر ضدك 💼.

## 4. نموذج عرض سعر قابل للتعبئة

```text
عرض سعر رقم (…) — التاريخ (…)
العميل: … · رقم ملف المخالفة البلدية: …
نطاق أعمالنا: تشخيص المخالفة وفق لائحة التصنيف + رفع واقعي +
مخططات (كما هو/معالجة) + تقديم ومتابعة المعالجة عبر بلدي حتى الإغلاق.
البنود: 1) أتعاب الملف: …  2) الرفع: …  3) التصاميم: …  4) تعقيب/متابعة: …
خارج نطاقنا: الغرامة الرسمية (تسدد للجهة) · تنفيذ الإزالة/البناء (مقاول مستقل) ·
الفحوص المعززة · رسوم الرخص الرسمية.
ملاحظات: الأسعار لا تشمل VAT · صلاحية العرض: 30 يوماً.
```

## 5. مثال حسابي تدريبي 🧪

فيلا دورين في حي العريجاء (🧪): ملحق خلفي بُني بلا رخصة + سطح مسقوف.
- أتعاب التشخيص والملف: 3,500
- رفع مساحي: 2,000
- تصاميم (كما هو + معالجة): 4,500
- تعقيب حتى الإغلاق: 2,500
- **أتعاب المكتب: 12,500 + VAT 📚**
- خارج نطاقنا 🧪: غرامة (فئة المخالفة) تُسدد للجهة + تنفيذ إزالة جزء الزائد (~6,000) + شرعنة 10484 (رسوم رسمية ⚠️ + تصميم مشمول).

**قاعدة التسعير:** كل ملف مخالفات يبدأ «مصعباً» — سعره مقدمات استثنائية موثقة بسبب الجولات المتكررة؛ وليس نسخة غالية من عرض السعر العادي 💼.
