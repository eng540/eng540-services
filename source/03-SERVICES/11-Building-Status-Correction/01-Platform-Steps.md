# الخدمة 11 — خطوات المنصة (بلدي + ناجز) — تصحيح وضع مبنى

> إصدار 1.0 · 2026-11-10 · ⚠️ شاشات المخالفات تتفاوت بين البلديات — الموصوف هنا وظيفي من المسارات الرسمية الموثقة.

## 1. بطاقة قنوات المنصة

| القناة | الاستخدام | الوثوقية |
|---|---|---|
| بلدي — قنوات البلاغات/الطلبات البلدية | تقديم المعالجة ومتابعتها (الشكل يختلف حسب البلدية) | ⚠️ واجهة-بلدية |
| خدمة 10484 «إضافة وتعديل مكونات بناء» | شرعنة المكونات المعالجة بعد الموافقة | ✅ |

| ناجز | وكالات وإقرارات وتوثيق عند الحاجة | 📚 |
| الدعم: 199040 / infocs@momah.gov.sa | استفسارات رسمية | ✅ |

## 2. مسار المستفيد (كما هو وظيفياً)

### مرحلة أ — استقبال المخالفة وتشخيصها (داخل المكتب)
1. **سحب الإشعار/البلاغ** برقمه من العميل (نسخة ورقية أو عبر حساب بلدي ⚠️) — سجّل: رقم البلاغ، التاريخ، الجهة، نص المخالفة.
2. **مطابقة نص المخالفة بلائحة التصنيف** ✅ (DownloadAttachment/45): حدد البند والفئة — هذا يحدد الغرامة المتوقعة وخيار المعالجة.
3. **فحص الرخصة:** هل وُجدت رخصة أصلية؟ هل المخالفة «عكس رخصة» أم «بلا رخصة»؟ (يحدد إن كان المسار 10484 أهلياً).

### مرحلة ب — بناء ملف المعالجة
4. إسناد مكتب هندسي + مساح (رفع واقعي + مخططات «كما هو») 💼.
5. صياغة «مخطط المعالجة»: ما يُعتمد (وفق الاشتراطات) وما يُزال.
6. تجهيز الإقرارات (ملكية، إخلاء إن لزم، سداد غرامة 📚).

### مرحلة ج — التقديم الرسمي
7. تقديم المعالجة عبر القناة البلدية المعتمدة ⚠️ (بلاغ/طلب/حجز خدمة) — أدخل البيانات كما هي دون تجميل.
8. أرفق: مخططات، رفع، صور قبل، إقرارات، الرخصة الأصلية.
9. متابعة الحالة عبر نفس القناة (بالفترة المعلنة لكل بلدية ⚠️).

### مرحلة د — قرارات المراجعة
10. **قبول مبدئي** → التوجيه الرسمي: اعتماد عبر 10484 و/أو إزالة عبر 10473.
11. **طلب استيضاح** → رد موثق خلال جولة واحدة (لغة معيارية جاهزة في `05-Problems-Cases-Exam.md`).
12. **رفض** → الاعتراض عبر منصة الاعتراضات الموحدة ✅/⚠️ أو تصحيح وفق الملاحظات.

### مرحلة هـ — التنفيذ والإغلاق
13. سداد الغرامة **مباشرة للجهة** ✅ (لا عبر المكتب).
14. تنفيذ الاعتماد عبر 10484 (رفع وتصاميم رسمية) ✅ أو الهدم الجزئي عبر 10473 ✅.
15. التوثيق البعدي: صور بعد، محضر تنفيذ داخلي.
16. طلب الإغلاق/التأكد من الإقفال في النظام البلدي ⚠️ — احصل على وثيقة أو لقطة شاشة برقم مرجعي.
17. أرشفة: الرقم المرجعي + كل مراسلات الجولة الموثقة.

## 3. جدول حالة التحقق لكل خطوة

| الخطوة | الحالة | المصدر |
|---|---|---|
| 10484 و10473 متاحتان رسمياً | ✅ | صفحات الخدمات ودليل المستخدم |
| القرار المساحي لغرض الهدم دون رخصة بناء | ✅ | أسئلة بلدي الشائعة |
| لائحة التصنيف كمرجع فئات | ✅ | الرابط الرسمي |
| منصة الاعتراضات الموحدة | ✅ منتج · ⚠️ مساراً | بلدي/all-products |
| شاشة تقديم المعالجة وإقرار الإغلاق | ⚠️ | تتفاوت حسب البلدية — تحقق عند كل حالة |
| سداد الغرامات والمدد الرسمية | ⚠️ | وفق اللائحة المطبقة والجهة |

## 4. أخطاء المنصة الشائعة
1. تقديم المعالجة قبل التشخيص الوثائقي → رفض متكرر.
2. خلط «الإغلاق الإجرائي» مع «مطابقة الرخصة» — الثاني يمر حتماً بـ10484.
3. الاعتراض بأسلوب عاطفي بدل الرد الفني الموثق.
4. عدم الاحتفاظ برقم مرجعي لكل رسالة — يجعل المتابعة استحالة.
