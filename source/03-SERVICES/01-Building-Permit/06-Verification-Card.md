# 06 — بطاقة التحقق والتأشير التنفيذية: إصدار رخصة البناء

> إصدار 1.0 · تاريخ التحقق: 2026-11-15
> بطاقة تعريف الخدمة وقائمة فحص الوثائق وتدقيق الاشتراطات والتتابع التنفيذي — جاهزة للتأشير المكتبي والميداني.
> مفتاح التأشير: ☐ متوفر/مطابق · ☐ غير متوفر/نواقص · ☐ تم التنفيذ · ☐ لا ينطبق

## بطاقة التعريف

| البند | القيمة |
|---|---|
| المنصة الرسمية | منصة بلدي — الرخص الإنشائية (خدمة إصدار رخصة البناء) ✅ |
| المرجع النظامي والكود | دليل إجراءات الرخص الإنشائية + كود البناء السعودي SBC 1101/201 ✅ |
| الرسوم والصلاحية | رسوم الرخصة البلدية تُحتسب من حاسبة الرسوم عند إصدار الفاتورة ⚠️ — أُورِد نطاق المباني السكنية 0.60–3.00 ر.س/م² ⚠️ · صلاحية الرخصة تتحقق من نصها ⚠️ |
| المتطلب السابق (التتالي) | صك إلكتروني محدث (خدمة 2) + قرار مساحي سارٍ بغرض البناء (خدمة 4) ✅ |

| # | الوثيقة المطلوبة | شرط القبول النظامي والفني | موجود ☐ | غير متوفر ☐ |

| 2 | القرار المساحي | صادر من منصة بلدي ومعتمد من البلدية بغرض البناء وسارٍ الصلاحية ✅ | ☐ | ☐ |
| 3 | تقرير فحص التربة الجيوتقني | صادر من مختبر معتمد ويحدد جهد التربة ومنسوب الأساسات ونوع الأساسات ✅ | ☐ | ☐ |
| 4 | المخططات الهندسية (معماري/إنشائي/MEP) | بصيغة DWG وPDF ومطابقة لكود البناء واشتراطات العزل الحراري ✅ | ☐ | ☐ |
| 5 | عقد المكتب الهندسي المصمم والتعهدات | تعاقد إلكتروني موثق عبر منصة بلدي مع إقرار تطبيق الكود ✅ | ☐ | ☐ |
