## 2. أشجار القرار (نصية — تتفرع بالسبب)

### شجرة أ: تعارض حدود صك/مخطط/واقع
```
اكتُشف فرق بين الصك والمخطط/الواقع
├─ الفرق ضمن هامش قياس مهني بسيط 📚
│   └─► أرفق المساحة الفعلية في النتائج + أكمل المعاملة
├─ الفرق جوهري وثائقي (مساحة صك ≠ مخطط معتمد)
│   ├─ الصك يزيد عن المخطط؟ → مسار تحديث الصك (خدمة 2) وفق القياس ⚠️ إجراء العدل
│   ├─ المخطط أحدث من الصك؟ → الاعتماد على المخطط غالباً 📚 + تثبيت عند الأمانة
│   └─ تضارب مصدرين؟ → المصدر الرسمي الأحدث يغلب مع توثيق التضارب (معايير المعرفة §9)
└─ الفرق سببه تعدي (صكّي يفقد لأمهّة/جار)
    → انتقل لشجرة ب أو ج
```

### شجرة ب: تعدي جار
```
تعدي موثق بالرفع الميداني
├─ الجار يقر بالخطأ ويرضى بالإزالة؟
│   ├─ نعم → جدول إزالة + ملاحظة بالنتائج + متابعة قبل بناء العميل 💼
│   └─ لا →
├─ التعدي على أرض خاصة (جار)
│   ├─ مسار ودّي: تسوية مكتوبة بين الطرفين (مكتب يوثق فقط 💼)
│   └─ مسار رسمي: بلاغ/طلب للبلدية (أداة رقابية) 📚 و/أو قضية حقوق لدى محامٍ مرخص 📚
│       └─ قرار القرار المساحي: يُكمل على حدود الوثيقة ويشير للتعدي 📚
└─ التعدي يخص أملاك عامة/دولة → شجرة ج
```

### شجرة ج: تداخل مع أملاك الدولة
```
تداخل موثق (شارع مبسوط/أرض فضاء)
├─ التداخل جزئي هامشي
│   ├─ يمكن تعديل حدود المشروع داخلياً (تراجع بناء) → أكمل القرار + علم العميل بالارتداد 📚
│   └─ لا يمكن → استشارة البلدية عن نطاق المسار ⚠️ قبل المتابعة
└─ التداخل جوهري
    ├─ أوقف أي تصرف فوراً 📚
    ├─ أظهر التداخل في النتائج لا تخفه (مسؤولية مهنية 💼)
    └─ اتبع قناة الجهة (بلدية/الأملاك) ⚠️ الإجراءات تختلف حسب الجهة والمنطقة
```

### شجرة د: رفض/تعثر القرار — من أين جاء الرفض؟
```
عاد الطلب بملاحظات/رفض
├─ طبقة مستندات (صك/مرفق/صيغة) → استوفِ المتطلب الرسمي ✅ ثم أعد الإرسال
├─ طبقة مساحية (نتائج/دقة/اتساق) → راجع مساحياً وأعد الرفع إن لزم 📚
├─ طبقة اشتراطات (مخطط/أملاك/تعارض) → شجرة أ/ب/ج بحسب السبب
├─ طبقة ملكية (ملكية غير مطابقة/ورثة/وكالة) → وثّق التمثيل ✅ أو عالج الوثيقة (خدمة 2)
└─ طبقة إجرائية (تعثر زمني) → تصعيد 199040 ✅ وفق مدة 10 أيام المعلنة ✅
```

### شجرة هـ: جار ممتنع
```
جار لا يحضر أو يمنع
├─ لم يحضر فقط → القياس على حدود الوثيقة + توثيق الدعوة والغياب 📚
├─ حضر واعترض لفظياً → وثّق الاعتراض في النتائج ولا تجادل؛ القرار للجهة 📚
├─ منع فعلي (قفل/حرس)
│   ├─ محاولة ثانية بتوقيت آخر + إشعار موثق 💼
│   └─ استمر بالمنع → ارفع النتائج بتفسير مكتوب؛ البلدية أداة الاستدعاء لديها 📚⚠️
└─ الجار رفع اعتراضاً رسمياً على القرار
    → منصة الاعتراضات الموحدة/قنوات البلدية ✅ + حزمة توثيق المكتب تدعم الطلب
```

## 3. حالة عملية (أ) — سلسة: أرض 400م² بلا نزاع بغرض البناء 🧪
> بيانات افتراضية كاملة للتدريب.

**الخلفية:** أبو محمد، أرض سكنية 400م² بمخطط معتمد، صك إلكتروني محدث، لا خلافات. يريد رخصة بناء.
**1) التشخيص:** غرض محسوم: قرار مساحي **بغرض البناء** ✅ (متطلب رخصة رسمي).
**2) الوثيقة:** صك محدث ✅ — لا حاجة لخدمة 2.
**3) التعاقد:** عرض سعر 🧪: أتعاب مساح 900 + إدارة 400 + ضريبة (انظر 04 §3.4)؛ الرسوم البلدية لاحقاً من فاتورة بلدي ⚠️.
**4) التقديم:** المالك عبر لوحة التحكم: الطلبات → تقديم جديد → طلب إصدار → التقارير المساحية → إصدار تقرير مساحي ✅؛ البيانات: أمانة/بلدية، الغرض: بغرض البناء، نوع الوثيقة: صك؛ المسار: **سريع** باختيار مساح معتمد ✅؛ المرفق: صورة وثيقة الملكية ✅.
**5) الميدان:** حجز خلال يومي عمل 💼؛ زيارة واحدة 45 دقيقة: RTK (حل Fix)، 4 أركان، مساحة فعلية 401.2م² (فرق +1.2م² = ضمن هامش بسيط 📚)، صور 12، لا تعارض.
**6) الرفع والمراجعة:** النتائج رفعت بعد يومي عمل 💼؛ المسار السريع: مراجعة المساح المعتمد دون ملاحظات.
**7) السداد والإصدار:** فاتورة بلدي ← سداد إلكتروني ✅ ← إصدار القرار وطباعته من حساب المستفيد ✅ في اليوم 8 من التقديم (ضمن المدة المعلنة 10 أيام ✅).
**8) الاستخدام:** القرار أُدخل في طلب رخصة البناء (المكتب المصمم يختار «التقرير المساحي للأرض» ✅) ← بدء رخصة (خدمة 1).
**دروس الحالة:** فرق مساحة صغير لا يعطل المعاملة إذا وثق؛ المسار السريع + جاهزية ميدانية = أقصر دورة 💼.

## 4. حالة عملية (ب) — استثنائية: نزاع حدود + تعدي جار 🧪
> بيانات افتراضية كاملة للتدريب.

**الخلفية:** أم خالد، أرض 500م²، جارها الشرقي شيّد غرفة خدمية يغلب أنها داخل حدّها 60سم (قياس مبدئي). تريد قراراً ثم بناء.
**1) التشخيص المبكر (خطوة 4):** كشف التعدي قبل التعاقد → حُدد في العرض «زيارة توثيق نزاع» وامكانية زيارة ثانية 💼.
**2) الغرض:** بغرض البناء ✅ (الهدف النهائي رخصة بناء).
**3) الوثيقة:** صك محدث، المخطط معتمد، الحدود المكتوبة «يحده شرقاً: ملكية فلان» — وصف وثائقي عام.
**4) التقديم:** مسار **سريع** بمساح معتمد (تحكم أدق في توثيق النزاع) 💼.
**5) التنسيق الميداني (خطوة 15):** دعوة الجار رسالة موثقة قبل 48 ساعة للحضور (توثيقاً 📚)؛ حضور ابن المالكة كممثل.
**6) الزيارة (خطوة 16):** قياس RTK كامل؛ تعدي موثق: غرفة الجار تتقدم 60سم بامتداد 9م (≈5.4م² 🧪)؛ صور 20 + شاشة الجهاز.
**7) الملاحظات (خطوة 17 — شجرة ب):** الجار حضر واعترض لفظياً لكنه لم يمنع؛ القرار التشغيلي: **الرفع على حدود الوثيقة** + وثائق التعدي في النتائج + تنبيه مكتوب لأم خالد أن الحسم قناة بلدية/قضاء 📚، وأن المكتب لا يوقع تسويات ملكية.
**8) الرفع والمراجعة:** النتائج مع «ملاحظة تعدي موثق»؛ المساح المعتمد طلب توضيحاً → رد خلال 24 ساعة بالصور (خطوة 18-ج) ← اعتماد.
**9) السداد والإصدار:** فاتورة ← سداد ✅ ← إصدار القرار (يوم 12 — زيارة ثانية أضافت 3 أيام 💼🧪).
**10) التفرع:** أم خالد أمام خيارين: (أ) بناء على حدودها مع ترك التعدي لقناة البلدية/القضاء بالتوازي؛ (ب) تسوية ودية مع الجار. القرار المساحي صار **برهانها الفني المحايد** في المسارين 📚.
**دروس الحالة:** النزاع لا يوقف الخدمة إن وُثق؛ الحد الفاصل بين «توثيق» و«حسم» هو صمام أمان المكتب المهني 💼📚؛ عدم إخطار الجار كان سيحوّل الزيارة لمشاجرة (شجرة هـ).

## 5. اختبار الإتقان (10 أسئلة — 6 معرفة + 4 قرار)
> معيار النجاح: **80%** (8/10). أجب قبل قراءة المفتاح.

### أسئلة المعرفة (1–6)
**س1:** ما الاسم الرسمي للخدمة على منصة بلدي، وفي أي منتج يقع؟
**س2:** اذكر المتطلبات الرسمية الثلاثة للخدمة كما وردت في صفحتها.
**س3:** كم تبلغ صلاحية القرار المساحي، وما الإجراء عند انتهائها؟
**س4:** علاقة القرار المساحي برخصتي البناء والهدم — اذكر النص الرسمي لكل منهما.
**س5:** ما الفرق بين مسار «المساح المعتمد» ومسار «الأمانة/البلدية» في هذه الخدمة؟ ومن يختار كل منهما؟
**س6:** ماذا تفعل إذا أراد مالك استخدم قراراً قديماً لغرض مختلف؟ ولماذا قبل إصدار الرخصة تحديداً؟

### أسئلة القرار (7–10)
**س7:** مالك صكه يظهر فيه 450م² والقياس الميداني 401م² (مخطط معتمد يقول 400م²). ما خطواتك بالترتيب؟
**س8:** أثناء الزيارة تبين سور جار يتقدم 60سم داخل الأرض والجار يمنعكم من القياس قرب حدّه. هل توقفون المعاملة؟ فصّل قرارك.
**س9:** تبين أثناء الرفع أن جزءاً من الأرض يقع على شارع مبسوط. ما أول ثلاث تصرفات ممنوعة عليك، وما المسار الصحيح؟
**س10:** عميل لديه قرار مساحي عمره سنتان و7 أشهر بغرض «الهدم» لكنه قرر البناء. ماذا تنصحه بالضبط؟
