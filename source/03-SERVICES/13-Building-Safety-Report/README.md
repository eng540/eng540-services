## القسم الأول — فهم الخدمة (الأسئلة الـ12)

### 1.1 ما هي الخدمة؟ (الهيكل الثلاثي الموثق)
عمل هندسي تقييمي وفحص فني لمبنى قائم يُنفذه مكتب هندسي مصنف (فاحص فني / استشاري إنشائي وسلامة) بمرجعية كود البناء السعودي (**SBC 901** للمباني القائمة، **SBC 310** لتأهيل الخرسانة، و**SBC 801** للحماية من الحريق)، وينقسم في الواقع التنظيمي السعودي إلى **ثلاثة مسارات متكاملة حسب الغرض** (تحقق حي **2026-11-14** ✅):

1. **المسار البلدي الرسمي — خدمة «إصدار تقرير فني» في منصة بلدي (`10498` / `node/10933`):** خدمة إلكترونية رسمية (تاريخ إصدارها `2022-11-17`، الزمن الأقصى للمرحلة **10 أيام عمل** ✅) تتيح للمستفيد طلب إصدار تقرير فني عبر فاحص فني (مكتب هندسي مصنف) لإصدار **«شهادة تأكيد السلامة»** استناداً إلى رخصة بناء أو قرار مساحي.
2. **مسار الدفاع المدني — بوابة «سلامة» وخدمة رفع تقارير أنظمة السلامة (`998.gov.sa`):** عبر البوابة الرسمية للمديرية العامة للدفاع المدني (`https://998.gov.sa/`، تسجيل DGA `20251109914`) و**بوابة سلامة** (`salamah.998.gov.sa`) و**خدمة رفع تقارير أنظمة السلامة والوقاية من الحريق** (`https://998.gov.sa/app-saftyreport`) وقوائم المكاتب الهندسية الاستشارية وشركات السلامة والمصاعد المعتمدة ✅.
3. **المسار الاستشاري المهني المباشر (Condition Assessment):** فحص بصري ومخبري (شميدت، قلوب خرسانية، GPR) لإصدار تقرير فني موقّع من مكتب هندسي مصنف لدى الهيئة السعودية للمهندسين (`saudieng.sa` ✅) لأغراض قرار الترميم (5) أو الهدم (10) أو الفحص النافي للجهالة قبل الشراء أو التأمين أو الخبرة القضائية 📚💼.

### 1.2 التعريف النظامي والهندسي
- **نظامياً:** لا تعريف رسمي موحد متحقق منه لهذا التقرير كوثيقة مستقلة ⚠️ (لأن الخدمة ذاتها غير مُمنحة كخدمة إلكترونية موحدة). وجوده يظهر ضمنياً في المنظومة: خريطة التقارير الفنية بالمستودع تعرفه بأنه «تقرير سلامة المبنى: مهندس/مكتب بصلاحية تقييم — المالك/البلدية — قرار ترميم/هدم/استمرار» (`../../04-ENGINEERING/Technical-Reports/Technical-Reports-Guide.md` §1)، وسؤال شائع رسمي في خدمة الترميم يفصل بين المباني المرخصة وغير المرخصة ✅ (انظر 1.11).
- **هندسياً** 📚: عملية تقييم مبنى قائم بمنهجية ثلاثية المراحل: (1) **مراجعة مكتبية** (صك، رخص، مخططات، سجل صيانة)؛ (2) **فحص ميداني** — معاينة أولية ثم فحص بصري مفصل لعناصر النظام الإنشائي (أساسات ظاهرة، أعمدة، ركائز/كرانيش، بلاطات، جدران حاملة وغير حاملة، عزل ومياه) مع توثيق شروخ وقياسات؛ (3) **فحوص معززة عند الحاجة** (اختبارات خرسانة، رادار اختراق أرضي GPR…) 📚⚠️، ثم تحليل وفق كود البناء السعودي وتصنيف الحالة وإصدار التقرير.
- **المرجعية الفنية المتحققة** ✅ [متحقق: المركز السعودي لكود البناء — قائمة كود 2024، https://www.sbc.gov.sa/ar/BC/Pages/BuildingCode/BC.aspx?year=2024، تحقق 2026-11-10]:
  - **SBC 901 — الكود السعودي للمباني القائمة** (الجزء المباشر لتقييم وتصحيح المباني القائمة).
  - **SBC 310 — الكود السعودي لإصلاح وتأهيل ومعالجة المنشآت الخرسانية للمباني القائمة** (مرجع التوصيات الإنشائية للترميم والتقوية).
  - **SBC 201 — كود البناء السعودي العام** (نطاق الكود: «ضمان السلامة والصحة العامة» — النص التعريفي الرسمي على موقع المركز).
  - **SBC 301** (الأحمال والزلازل والرياح — مرجع مقاومة المبنى للأحمال)، **SBC 303** (التربة والأساسات)، **SBC 304** (المنشآت الخرسانية)، **SBC 305** (المنشآت الطوبية)، **SBC 306** (المنشآت الفولاذية)، **SBC 801** (الحماية من الحرائق)، **SBC 902** (المباني التاريخية — للحالات التراثية).

### 1.3 ما الهدف من الخدمة؟
1. إعطاء قرار فني موثق ومسؤول عن: **هل المبنى آمن للاستخدام؟** وهل يُرمم أم يُهدم؟ وما الأولوية والتسلسل؟
2. تحويل «شكوك» (شروخ، مياه، هبوط) إلى **تشخيص هندسي مبني على فحص موثق بالصور والقياسات**.
3. تزويد الجهة المستقبِلة (حسب الغرض) بأساس لقرارها: بلدية (ترميم/هدم/تصحيح وضع)، دفاع مدني (سلامة إشغال)، تأمين (حادثة/تعاقد)، قضاء/تحكيم (نزاع)، ممول (تمويل/شراء).
4. حماية المالك والمهندس معاً: التقرير واضح النطاق والحدود يمنع تفسيره بغير غرضه.

### 1.4 لماذا يحتاجها العميل؟
- لأن أي من الخدمات اللاحقة (رخصة ترميم 5، رخصة هدم 10، تصحيح وضع 11) **تحتاج أساساً فنياً** يبرر اختيار المسار 📚 (خريطة العلاقات: س3، س4، س7).
- لأن المنازعات (شرار جيران، خلل مقاول، شراء عقار مشكوك فيه) تُحسم بوثيقة مهنية محايدة موقعة.
- لأن «المبنى المتصدع» قد يكون آمناً (شروخ تشطيب) أو خطراً (فشل إنشائي جوهري) — الفرق لا يُدرك إلا بالفحص المتخصص.
- لأن شركات التأمين والممولين يطلبون إثبات الحالة الفنية قبل التعاقد 💼.

### 1.5 من العملاء المستهدفون؟
| العميل | الغرض الشائع |
|---|---|
| مالك فيلا/دور سكني قديم | قرار ترميم أو إثبات سلامة قبل البيع 💼 |
| مالك/مستثمر مبنى تجاري | سلامة الإشغال وتقييم قبل تعاقد إيجار طويل |
| مشترٍ محتمل (عبر وكيل) | due-diligence فني قبل الشراء 💼 |
| شركة تأمين / مؤمَّن عليه | توثيق حالة قبل/بعد حادثة (حريق، سيول، انهيار جزئي) 💼 |
| محامٍ/محكمة (عبر خبير) | إثبات فني في نزاع 📚 |
| شركة إدارة عقارات | تقييم دوري لمحفظة مبانٍ 💼 |
| جهة حكومية/بلدية | إسناد تقييم مبانٍ متضررة في نطاقها 📚 |

### 1.6 متى تكون إلزامية؟
- **لا يوجد تشريع متحقق يوجبها بشروط موحدة** ⚠️ — إلزاميتها **مشتقة من الغرض**:
  - عندما تشترطها الجهة المستقبِلة للقرار: بلدية تطلب تقريراً فنياً قبل قبول طلب ترميم/هدم أو لتبرير تصحيح وضع 📚⚠️ (يختلف حسب البلدية والحالة — لا نص موحد).
  - عندما يظهر بناء خطر: الإبلاغ النظامي بالبلدية/الدفاع المدني قد يفتح ملفاً يُطلب فيه تقييم فني ⚠️ (مسار الحالة «ب» في 05).
  - في النزاعات: القضاء يكلف خبيراً، ويدعو الأطراف لتقديم تقاريرهم 📚.

### 1.7 متى تكون اختيارية أو غير مناسبة؟
- اختيارية تماماً كعمل مهني: أي مالك يستطيع إسنادها دون طلب جهة 💼.
- **ليست البديل عن**: رخصة الترميم (خدمة 5) أو رخصة الهدم (خدمة 10) أو تصحيح الوضع (خدمة 11) — التقرير يسبقها ويبررها ولا يعوضها.
- **ليست**: رفعاً مساحياً (خدمة 4/8)، ولا دراسة تربة جديدة، ولا تصميماً للترميم (تصميم المعالجات عمل خدمة 5/مكتب مصمم).
- **ليست** شهادة رسمية معتمدة حكومياً بذاتها — إن لم تعتمدها الجهة المستقبِلة فهي دليل فني مهني (مدى اعتمادها متغير ⚠️).

### 1.8 الحالات المستدعية (الشائعة عملياً)
| الحالة | الغرض الغالب | النتيجة المتوقعة |
|---|---|---|
| فيلا 25+ سنة بشروخ متعددة | قرار ترميم | تصنيف + نطاق ترميم بالأولوية |
| مبنى شارف الانهيار بعد سيول/حريق | إثبات خطر وإخلاء | تصنيف «خطر» + مسار إبلاغ رسمي ⚠️ |
| شروخ ظهرت في مبنى الجار بعد حفر/هدم مجاور | نزاع | تقرير محايد يربط/ينفي السبب |
| طلب تمويل/بيع عقار قديم | إثبات سلامة 💼 | تقرير «سليم/يحتاج صيانة» |
| مبنى بلا رخصة تريد البلدية معالجته | تصحيح وضع (11) | تقرير يحدد: تنظيم/ترميم/هدم 📚 |
| عزل فاشل ومشاكل رطوبة متكررة | توصيات صيانة | تقرير نطاق متوسط |

### 1.9 المشكلات التي تحلها، وعلاقتها بالخدمات الأخرى
- يحل: تحيّز تقدير المالك، تناقض آراء متضاربة، غياب مبرر فني لقرار بلدي، خطر استخدام مبنى متدهور دون وعي.
- **علاقتها بالمنظومة** (`../../00-STRATEGY/Services-Relations-Map.md` §2 — سطر 13 والسيناريوهات س3/س4/س7):
  - **تعتمد على**: صك محدث (خدمة 2) عند الغرض الرسمي، مخططات الرخصة الأصلية إن وُجدت، زيارة ميدانية (لا تنفذ دونها).
  - **تفتح بعدها**: رخصة ترميم (5) / رخصة هدم وإشرافها (10) / تصحيح وضع (11) / استمرار استخدام موثق / دليل فني لنزاع أو تأمين.

### 1.10 خصوصيات مهمة
1. **تعدد أطراف الاستلام هو جوهر الخدمة**: نفس المبنى قد يُفحص مرة واحدة ويُعد تقرير بتوزيعات (نسخة بلدية بصياغة «سند لطلب ترميم»، نسخة تأمين بشيء آخر) — بشرط عدم تناقض المضمون والنتيجة 📚.
2. **الغرض يحدد كل شيء**: تقرير «عام» يرفضه أغلب المستلمين — صياغة الغرض تطابق ما تطلبه الجهة (`Technical-Reports-Guide.md` §3: «الغرض مطابق لما تطلبه الجهة — تقرير عام يُرفض غالباً» 💼/📚).
3. **زيارة ميدانية إلزامية**: لا يصدر تقييم سلامة جاد من مكتب دون زيارة؛ الفحص عن بعد (صور المالك) يصلح فقط لمرحلة التسعير الأولي 📚.
4. **الفحوص المعززة**: المتاح سوقياً (مطرقة شميدت، GPR، قلوب خرسانية، اختبارات مختبرية) 📚 — متطلبات اعتماد المختبرات وشهادات الفاحصين تفصيلها غير متحقق ⚠️.
5. **قنوات الاعتماد الرسمية الموثقة** ✅: خدمة بلدي **«إصدار تقرير فني» (`10498`)** لإصدار «شهادة تأكيد السلامة»، ومنصة الدفاع المدني **`998.gov.sa` (`salamah.998.gov.sa` و`app-saftyreport`)** لتقارير أنظمة السلامة والوقاية من الحريق، مع القنوات التعاقدية/القضائية للتأمين والمحاكم.
6. **الحد المهني**: التصنيف والإصدار صلاحية مكتب هندسي استشاري مصنف لدى **الهيئة السعودية للمهندسين (`https://www.saudieng.sa`)** ✅ (أو المكاتب وشركات السلامة المعتمدة لدى الدفاع المدني عبر قوائم `998.gov.sa` لشق الحريق ✅). **لا توقيع من منسق خدمات** (`Knowledge-Standards` §6).

### 1.11 الفرق عن الخدمات المشابهة (الحدود الحاسمة)

### 1.12 نتائج عدم تنفيذها
- **على المالك**: قرار ترميم/هدم مبني على اجتهاد غير فني — إما تكاليف زائدة أو خطر دائم؛ ورفض لاحق لطلباته لدى الجهات لغياب السند الفني 📚.
- **على سلامة الأشخاص**: مبنى متدهور يستمر في الاستخدام دون تقييم = خطر غير محسوب (أخطر نتيجة) 📚.
- **على النزاع**: بلا تقرير محايد، يتحول الخلاف الفني إلى مزاحمة إفادات.
- **على المكتب/المنسق**: أخذ قرار بمسار (ترميم مثلاً) ثم تُكتشف أخطاء أغلى — تُرفع المسؤولية على من أشار دون تقييم موثق 📚.

| 6 | **مستقبِل الاعتراضات**: الجهة التي بُني عليها القرار (بلدية/محكمة/تأمين) + تقييم مهني ثانٍ بطلب الطرف | طلب إعادة تقييم أو تقييم مضاد | 📚/⚠️ |

> فصل الأدوار ملزم: المنسق يستقبل وينسق ويجهز — **لا يفحص بذاته ولا يوقّع**؛ التوقيع للمهندس صاحب الصلاحية فقط (`../../00-STRATEGY/Knowledge-Standards.md` §6).

## علاقة الخدمة بالمنظومة (قبل/بعد)

```
صك محدث (2) عند الحاجة · مخططات الرخصة الأصلية إن وُجدت
        │
        ▼
★ الخدمة 13: إعداد تقرير سلامة المبنى (عمل مهني — بلا منصة موحدة) ★
        │
        ├─ التوصية: ترميم ──→ رخصة ترميم (5) عبر بلدي 10481 ✅
        ├─ التوصية: هدم ────→ رخصة هدم (10) عبر بلدي 10473 ✅ + إشراف
        ├─ التوصية: تنظيم/معالجة مخالفة → تصحيح وضع (11) 📚
        ├─ التوصية: آمن للاستخدام → توثيق للمالك/التأمين/الممول 💼
        └─ الحالة: مبنى خطر ورفض المالك التصرّف → إبلاغ رسمي (بلدية/دفاع مدني) ⚠️
```

## الخدمات الفرعية / المسارات داخل الخدمة
- **تقييم كامل (إنشائي + معماري + خدمات)**: للقرارات الكبرى (ترميم كلي/هدم/نزاع) 📚.
- **تقييم نطاق محدود**: عنصر محدد (سطح، عزل، تصدع عمود واحد) بتقرير مختصر 💼.
- **تقييم ما بعد حادثة** (حريق/سيول/تصادم مركبة): أولوية سرعة وتوثيق قبل أي معالجة 📚.
- **مراجعة فحص مكتب آخر** (second opinion): نزاع أو تضارب تقييمين 📚 (شجرة قرار في 05 §2).

## تصنيف الخدمة ضمن الفئات السبع (`../../00-STRATEGY/Vision.md` §4)
- **أساسها الفئة 6 — الخدمة الاستشارية**: «تقييم المبنى، تقارير السلامة… — مستشار/مهندس بصلاحية توقيع» ✅ (نص الرؤية).
- تمتد للفئة 1 (هندسية) عند إضافة مخططات معالجة، وللفئة 7 (تعقيب) عند تقديم التقرير ضمن معاملة بلدية لاحقة 📚.

## حدود مسؤولية المكتب الهندسي في هذه الخدمة
- **يفعل**: معاينة وفحص بصري وتوثيق، تحليل ومطابقة مع الكود، تصنيف وتوصيات، توقيع التقرير وإقرار حدوده.
- **لا يفعل**: اعتماداً حكومياً (للجهة)، تصميماً تنفيذياً للترميم بغير إسناد (خدمة 5)، استبدال قرار البلدية بقراره، تلبية ضغط عميل «لطباعة سليم» — **الرفض الموثق واجب** (05 §2).
- **ما يتطلب جهة أخرى**: اختبارات مختبرية (مختبر معتمد ⚠️)، رادار (فريق متخصص)، هبوط واستواء (مساح)، إخلاء وإبلاغ رسمي (البلدية/الدفاع المدني ⚠️).
