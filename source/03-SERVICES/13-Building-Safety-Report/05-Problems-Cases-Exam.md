# الخدمة 13 — المشكلات، الحالات العملية، والاختبار

## 1. المشكلات الشائعة (8) — الأعمدة التسعة

| # | المشكلة | السبب | العلامة المبكرة | التأثير | المعالجة |
|---|---|---|---|---|---|
| 1 | غرض التقرير غامض | لم يُسأل «مَن سيقرأه؟» | عميل يقول «تقرير عام» | رفض الاعتماد لدى الطالب | صياغة الغرض والإحداثية قبل الفحص |
| 2 | صلاحية تقييم غير كافية | مكتب بلا تخصص إنشائي | توصيفات عامة بلا منهجية | التقرير غير مقبول | إسناد لمهندس تقييم إنشائي 💼 |

## 2. شجرة القرار

```text
طلب تقرير سلامة
├─ فيه خطر مباشر؟ → نعم: توصية إيقاف/إخلاء + إبلاغ رسمي ⚠️ فوراً (الأمان قبل كل شيء)
├─ من الطالب؟ (جهة رسمية/متعاقد/مالك) → يحدد الإحداثية والصيغة
├─ أي مبنى؟ (سكن/سطح سكن/ملحق/تجاري) → نطاق الفحص
└─ النتيجة: سليم للإشغال / صالح بشرط / متدهور - ترميم (خدمة 5) / خطر - هدم (خدمة 10)
```

## 3. حالتان عمليتان 🧪

### الحالة أ — السلسة
تقرير لملحق سكني جديد قبيل طلب فرز (خدمة 3): فحص بصري موثق + صور + جدول ملاحظات + نتيجة «صالح للاستخدام» → مُقبل لدى الجهة الطالبة. **الدرس:** الغرض المكتوب بدقة = نصف قبول التقرير.

### الحالة ب — الاستثنائية المركبة
عمارة 4 أدوار، شقوق مائلة ظهرت أثناء هدم جار. التسلسل: توثيق الحالة **قبل** استمرار الهدم الجار (صور + خريطة شقوق) → فحص معزز 📚 → تقرير «صالح بشرط + مراقبة» → عرض على المالك تسجيل مراقبة دورية أثناء هدم الجار → عند أي تطور: توثيق جديد كمقارنة. **الدرس:** التقرير هنا «تأمين وثائقي»، وقيمته بالحصر قبل الحدث لا بعده.

## 4. اختبار الإتقان (10 أسئلة — النجاح 80%)

**معرفة (6):**
1. ما أول حقل في أي تقرير سلامة ولماذا؟ (الغرض — يحدد الإحداثية والصيغة والجهة)
2. متى يستلزم التقرير فحوصاً معززة؟ (شقوق إنشائية/شك/عمر/تدهور ظاهر)
3. ما الفرق بين «صالح للاستخدام» و«صالح بشرط»؟ (الأخير ملزم بتوصيات + مراقبة)
4. لماذا يوثق التقرير قبل هدم الجار وليس بعده؟ (الحصر قبل الحدث)
5. ما حدود دورك بعد نتيجة «خطر»؟ (إيقاف/إبلاغ رسمي — لا تفاوض ولا تسويق للنتيجة)
6. هل يصلح التقرير لعميل آخر؟ (لا — «للغرض المحدد فقط»)

**قرار (4):**
7. عميل: «اكتبها سليمة 100% وأضمن لك عملك سنوات» — ردك الموثق؟
8. وجدت شقاً مائلاً عرضه يتوسع بوضوح — ترتيب أفعالك الأولى؟
9. جهة طالبة رفضت التقرير لضعف التوثيق — أصلاحك خلال 48 ساعة؟
10. المستأجر يريد نسخة «لتقاضي خصوصي» — تصرفك؟

**مفتاح (مختصر):** 7: رفض موثق + بديل «صالح بشرط التوصيات» يحمي الجميع؛ 8: لا توقيع على «سليم» — فحص معزز فوري + تنبيه خطر كتابي؛ 9: صور/خرائط شقوق/منهجية مذكورة + إعادة تقديم؛ 10: التقرير ملك للغرض المحدد — أي نسخة أخرى عبر مساره الرسمي وليس بقرارك المنفرد.
