# قاموس المصطلحات الفنية والنظامية (عربي–إنجليزي)

> إصدار 0.1 · 2026-11-10 · مرجع مشترك لكل ملفات المشروع

## أ. الملكية والتوثيق

| المصطلح | English | التعريف التشغيلي |
|---|---|---|
| صك الملكية | Title Deed | وثيقة إثبات الملكية الصادرة عن وزارة العدل؛ النسخة الحديثة إلكترونية عبر ناجز |
| القيد العقاري | Registry Entry | سجل العقار في منظومة التوثيق/السجل العقاري؛ مرجع مطابقة بيانات الصك |
| السجل العقاري | Real Estate Registry | منظومة التسجيل العيني بإدارة الهيئة العامة للعقار |
| التسجيل العيني | Real/In rem Registration | التسجيل على وحدة العقار نفسها بدل الشخص |
| الفرز | Subdivision (of deed) | تحويل صك واحد إلى صكوك مستقلة لكل وحدة |
| الدمج | Merging | توحيد صكين أو أكثر في صك واحد |
| الحصة | Share | نصيب ملكية في ملكية مشتركة (مثلاً 1/4) |
| الملكية المشتركة | Co-ownership | ملكية أكثر من شخص للعقار نفسه |
| التوكيل/الوكالة | Power of Attorney | توثيق صلاحية التمثيل؛ موثق إلكترونياً عبر ناجز |
| عقار/عين العقار | Real Estate / Property Unit | الأرض وما عليها معاً كوحدة تسجيل |

## ب. المساحة والأراضي

| المصطلح | English | التعريف التشغيلي |
|---|---|---|
| القرار المساحي | Survey Decision | قرار من البلدية (عبر بلدي) يثبت حدود/موضع الملكية لأغراض محددة (بناء/هدم/نزاع) |
| الكروكي | Survey Sketch | رسم مساحي تخطيطي يوضح الموقع والحدود والأبعاد |
| الرفع المساحي | Topographic Survey | قياس ميداني موثق للحدود والمناسيب بأدوات معتمدة |
| المخطط (العقاري) | Subdivision Plan | خطة تقسيم أرض إلى قطع معتمدة من البلدية |
| القطعة | Plot | وحدة الأرض داخل مخطط معتمد |
| المخطط المعتمد | Approved Plan | المخطط المصادق عليه من البلدية (مرجع الاشتراطات) |
| الإحداثيات | Coordinates | تموضع النقاط (عادة UTM/WGS84 في السعودية 📚) |
| المنسوب المرجعي | Reference Elevation | نقطة ارتفاع يُقاس عليها باقي المناسيب |
| المساحة (المسقط) | Built-up Area | مساحة بناء في المخطط الأفقي |
| الحد/الطرف | Boundary | خط الملكية بين عقارين |
| تعدي | Encroachment | بناء/احتلال يتجاوز حدود الملكية |
| الأملاك الدولة | State Lands | أراضٍ مملوكة للدولة — تعدي عليها مخالفة جسيمة |

## ج. البناء والترخيص

| المصطلح | English | التعريف التشغيلي |
|---|---|---|
| رخصة البناء | Building Permit | إذن البناء الرسمي من البلدية عبر بلدي |
| المكتب الهندسي المصمم | Design Engineering Office | المكتب المصنف الذي يعد التصاميم ويرفع الطلب |
| المكتب الهندسي المشرف | Supervising Office | المكتب الذي يشرف على التنفيذ ويصدر إشعارات البناء |
| مقاول مصنف | Classified Contractor | مقاول معتمد لدى الوزارة في بلدي (شرط رسمي) |
| شهادة اعتماد التصاميم | Design Approval Certificate | شهادة تُطبَع بعد مراجعة الفاحص الفني والأمانة قبل إصدار الرخصة |
| التأمين ضد العيوب الخفية | Latent Defects Insurance | وثيقة إلزامية للمباني غير الحكومية؛ الرخصة غير سارية قبل سدادها |
| شهادة الإشغال | Occupancy Certificate | شهادة إنجاز البناء الفعلي من البلدية |
| شهادة الامتثال | Compliance Certificate | تصدر استباقياً بعد الإشغال والسداد |
| إشعارات البناء | Construction Notifications | تقارير مرحلية يرسلها المكتب المشرف أثناء التنفيذ |
| الارتداد | Setback | المسافة الإلزامية بين حدود الأرض والبناء |
| نسبة البناء | Building Ratio / FAR | نسبة المساحة المسموح بناؤها من أرض القطعة |
| تمييز المخطط | Zoning | تصنيف المنطقة (سكني/تجاري/مختلط) الحاكم للاشتراطات |
| اشتراطات البناء | Building Requirements | قواعد البلدية: ارتدادات، ارتفاعات، مواقف… |
| كود البناء السعودي | Saudi Building Code (SBC) | الاشتراطات واللوائح الفنية الوطنية للمباني |
| الترميم | Restoration/Renovation | استعادة المبنى دون إضافة مكون أو تغيير إنشائي (تعريف بلدي الرسمي) |
| الهدم | Demolition | إزالة المبنى برخصة رسمية وإقرار خلو المبنى |
| البدروم/الملحق/الدور المكرر | Basement/Annex/Mezzanine | مكونات بناء تشترط عناصر خاصة في الرخصة |
| مخالفة بلدية | Municipal Violation | مخالفة معاقَب عليها وفق لائحة الغرامات البلدية |

## د. أدوات وبرامج

| المصطلح | English | الاستخدام |
|---|---|---|
| محطة إجمالية | Total Station | قياس مساحي دقيق للحدود والمناسيب |
| الملاحة/القمر الصناعي التفاضلي | GNSS / GPS-RTK | تحديد إحداثيات بدقة عالية ميدانياً |
| ميزان مساحي | Theodolite/Level | تسوية ومناسيب |

| نظم المعلومات الجغرافية | GIS | خرائط حضرية وتحليل عقاري (الخرائط الحضرية منتج رسمي في بلدي ✅) |
| دراسة التربة | Soil Investigation | تقرير جيوتقني — متطلب رسمي لرخصة البناء ✅ |

## هـ. تجارة وتشغيل

| المصطلح | English | التعريف |
|---|---|---|
| التعقيب | Follow-up/Processing | إدارة المعاملة إجرائياً من الرفع حتى المخرج |
| عرض السعر | Quotation | مستند تسعير: رسوم رسمية + تكاليف + أتعاب + ضريبة |
| الضريبة على القيمة المضافة | VAT | 15% على الخدمات (منذ 2020-07-01 📚) |
| الفاتورة الإلكترونية | E-invoice (Fatoora) | منظومة زاتكا للفوترة الإلزامية 📚 |
| RACI | Responsible/Accountable/Consulted/Informed | مصفوفة توزيع أدوار في سير العمل |
| SLA | Service Level Agreement | المدة المعلنة للخدمة (مثال: 10 أيام للإشغال ✅) |
