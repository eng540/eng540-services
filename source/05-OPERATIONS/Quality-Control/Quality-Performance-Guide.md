# دليل ضبط الجودة وقياس الأداء — مكتب الخدمات الهندسية

> إصدار 0.1 · 2026-11-10 · يغطي: مراقبة جودة الأعمال، قياس أداء المكتب وربحيته.

## 1. نقاط الفحص في دورة المعاملة (بوابات جودة)

| البوابة | ماذا نفحص | من يفحص |
|---|---|---|
| قبل التعاقد | اكتمال التشخيص + واقعية الموعد والسعر | منسق أول + مدير |
| قبل الرفع الرسمي | المستندات كاملة وصحيحة؛ المخرجات الفنية مطابقة للقوائم المعيارية | مراجع جودة |
| عند كل ملاحظة | فهم السبب الجذري + حل يحسمها لا يرقّعها | منسق المعاملة |
| قبل التسليم | صحة بيانات المخرج + تحققه الرسمي + شمول التسليم | مراجع جودة |
| بعد التسليم | رضا العميل + أخطاء سُجلت للتحسين | مدير المكتب |

## 3. سجل الأخطاء (قاعدة التعلم)

كل خطأ (رفض، ملاحظة، إعادة عمل، شكوى) يُسجل: التاريخ، الخدمة، نوع الخطأ (تشخيص/مستند/فني/متابعة)، السبب الجذري، التكلفة، الإجراء التصحيحي. مراجعة شهرية: أعلى 3 أنواع خطأ → تدريب مستهدف.

## 4. لوحة الأداء الشهرية (KPIs)

| المجال | المؤشر | الهدف النمطي 💼 |
|---|---|---|
| النمو | عدد المعاملات الجديدة | خط أساس +10% |
| الكفاءة | متوسط زمن إتمام لكل خدمة | ≤ المعايير + 20% |
| الجودة | نسبة الطلبات التي رجعت بملاحظات بعد الرفع الأول | < 25% |
| الجودة | نسبة التسليم من أول اعتماد | > 70% |
| المالية | التحصيل/الفوترة | > 90% |
| المالية | هامش الربح لكل خدمة | حسب سياسة المكتب |
| العملاء | رضا بعد التسليم (من 10) | ≥ 8 |
| العملاء | نسبة الشكاوى | < 5% |

## 5. الربحية على مستوى الخدمة

احسب شهرياً لكل خدمة: إيراد، رسوم حكومية منقولة، تكاليف خارجية، ساعات إدارية → هامش. قرارات مبنية على النتائج: رفع أسعار الخدمة المكلفة، إيقاف خدمة خاسرة، توظيف لموازنة الحمل.

## 6. مراجعة ربع سنوية للمعرفة

- تحديث المصادر المتغيرة (سجل التحقق `10-QUALITY-AND-UPDATES/`).
- تدريب الفريق على أعلى أنواع الأخطاء في السجل.
- مراجعة أسعار المقدمين الخارجيين (تحديث عروض).
