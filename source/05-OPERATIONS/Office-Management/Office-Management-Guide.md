# دليل إدارة المكتب — موارد، تسويق، مالية، دورات عمل

> إصدار 0.1 · 2026-11-10 · يغطي: إدارة المهندسين والمساحين، الموردين، التسويق، العلاقات، المالية، ودورات العمل اليومية/الأسبوعية/الشهرية.

## 1. إدارة المهندسين والمساحين (شركاء التنفيذ)

- قاعدة صلاحيات: التوقيع الهندسي والرفع المساحي ينفذه مصنفون/مرخصون — مكتب الخدمات ينسق ولا يستبدلهم.
- سجل مقدمين: لكل مهندس/مساح — التصنيف/الترخيص وتاريخه، مجالات قوته، أسعاره، جودة مخرجاته التاريخية، زمن استجابته.
- توزيع العمل: حسب نوع الخدمة + المدينة + الحمل الحالي؛ عميل كبير له مقدم أساسي وبديل.
- تقييم ربع سنوي: جودة (ملاحظات مرتجعة)، سرعة، مرونة — ثم ترتيب القائمة المفضلة 💼.

## 2. إدارة الموردين ومقدمي الخدمات

| المورد | الحاجة | معيار الاختيار |
|---|---|---|
| مساحون مرخصون | رفع/كروكي/تقارير | ترخيص سارٍ ⚠️ + أدوات حديثة (RTK) + دقة تاريخية |
| مختبرات تربة | دراسات جيوتقنية | اعتمادات لدى الجهات ⚠️ + سرعة |
| مكاتب هندسية مصنفة | تصميم/إشراف | تصنيف سارٍ + خبرة نوع المبنى 💼 |
| مقاولون | تنفيذ (يختاره المالك غالباً) | تصنيف في بلدي ✅ + سمعة |
| مكاتب تقييم/سلامة | تقارير متخصصة | صلاحية توقيع + قبول الجهات ⚠️ |

## 3. التسويق واستقطاب العملاء

- التموضع: «منظومة خدمات هندسية وعقارية كاملة من التشخيص حتى التسليم».
- قنوات فعالة قطاعياً 💼: التوصيات (الأقوى)، الشراكة مع مقاولين ومطورين، حضور مناطق العقارات، محتوى توعوي إجرائي (أسئلة الملاك المتكررة)، إعلانات موجهة محلياً.
- عروض الدخول: فحص مستندات أولي مجاني/رمزي + تشخيص مدفوع بسيط — يبني الثقة ويكشف الخدمة الملحقة.
- قياس: مصدر كل عميل مسجل → تركيز الإنفاق على القنوات الأعلى تحويلاً.

## 4. المالية: الإيرادات والمصروفات

- فصل محاسبي صارم: **رسوم حكومية تُحصَّل بالنيابة** (خزينة وسيطة) مقابل **إيرادات المكتب** — خلطهما يفسد القوائم.
- مصروفات أساسية: رواتب، اشتراكات برمجيات، أجهزة/معايرة، تنقل، تسويق، إيجار.
- تدفق نقدي: دفعات مقدمة تغطي التكاليف الخارجية قبل سدادها (لا تمويل ذاتي للمعاملات).
- تقرير شهري: إيراد لكل خدمة، هامش لكل خدمة، متأخرات، أعمار الذمم.

## 5. دورات العمل

### اليومية
- صباحاً: فتح المنصات (بلدي/ناجز) — أي إشعارات/ملاحظات جديدة؟ تحديث لوحة المواعيد.
- أثناء اليوم: تنفيذ المهام المجدولة (رفوعات، زيارات، ملاحظات) — كل إجراء يوثق لحظياً.
- مساءً: تحديث حالات المعاملات + رسائل العملاء المعلقة + تجهيز غد.

### الأسبوعية
- اجتماع 45 دقيقة: لوحة KPIs، معاملات متعثرة (قرار لكل واحدة)، مواعيد الميدان الأسبوع القادم.
- مراجعة مالية سريعة: فوترة الأسبوع، تحصيلات، متأخرات.
- تحديث سجل الأخطاء والمقدمين.

### الشهرية
- تقرير الأداء (05-OPERATIONS/Quality-Control) + ربحية الخدمات.
- مراجعة أسعار المقدمين + تحديث عروض الأسعار القياسية.
- تدريب قصير مستهدف (أعلى 3 أنواع أخطاء).

## 6. المخاطر التشغيلية العليا

1. اعتماد على مقدم واحد بلا بديل.
2. وعد عملاء بمواعيد جهات دون مصدر.
3. خلط أموال الرسوم الحكومية بإيرادات المكتب.
4. ملفات غير موثقة لحظياً (فقدان أدلة عند النزاع).
5. عدم الفصل بين دور التعقيب والتنفيذ المهني (توسع نظامي خطر).
