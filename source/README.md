# ENG540 — منظومة المعرفة والتشغيل للخدمات الهندسية في المملكة العربية السعودية

> **Engineering Services Intelligence & Operations System**
> موسوعة معرفية وتشغيلية وتدريبية شاملة للخدمات الهندسية والمساحية والبلدية والعقارية في السعودية.
> تاريخ إنشاء المشروع: 2026-11-10 · آخر تحديث: 2026-11-10 (الإصدار 0.1)

---

## 1. هدف المشروع

بناء مستودع معرفة يجعل المتعلم قادراً على:

- فهم أي خدمة من الخدمات الأربع عشرة هندسياً ونظامياً وإجرائياً.
- استقبال العميل وتشخيص احتياجه الحقيقي وتحديد الخدمة الصحيحة.
- تحديد المتطلبات والمستندات والجهات والمنصات والأدوات لكل خدمة.
- إدارة المعاملة من أول اتصال بالعميل حتى تسليم المخرج النهائي وأرشفته.
- معالجة الملاحظات والرفض والحالات الاستثنائية عبر شجرات قرارات عملية.
- تسعير الخدمة تجارياً وإدارة المكتب الهندسي وتشغيله.

**معيار النجاح النهائي:** إذا عُرضت معاملة حقيقية لأي خدمة من الأربع عشرة، يفهمها المتعلم ويشرح مسارها ويحدد متطلباتها ومنفذيها وتكلفتها ومخاطرها ويتابعها حتى التسليم.

## 4. بنية ملف الخدمة (موحّد)

كل مجلد خدمة يحتوي ستة ملفات بالترتيب:

1. `README.md` — فهم الخدمة (القسم الأول) + الجهات والمنظومة (القسم الثاني) + المخرجات النهائية (القسم العاشر) + مصفوفة الاكتمال (18 بنداً) + المصادر.
2. `01-Platform-Steps.md` — دليل المنصات الإلكترونية الخاصة بالخدمة خطوة بخطوة (القسم الثالث).
3. `02-Requirements-Documents.md` — المتطلبات والمستندات مع الجهات المصدرة وقوائم التحقق (القسم الرابع).
4. `03-Executive-Workflow.md` — الخوارزمية التشغيلية الكاملة من استقبال العميل إلى إغلاق الملف — 25 خطوة مفصلة (القسم الخامس، أهم ملف).
5. `04-Technical-Field-Costs.md` — الجانب الهندسي والفني (السادس) + الحجز والتنسيق الميداني (السابع) + الرسوم والتكاليف والتسعير (الثامن).
6. `05-Problems-Cases-Exam.md` — قاعدة المشكلات وشجرة القرارات (التاسع) + حالتان عمليتان + اختبار الإتقان.
