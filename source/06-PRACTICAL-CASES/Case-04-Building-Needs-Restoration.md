# الحالة العملية 4 — مبنى يحتاج ترميماً

> 🧪 بيانات افتراضية للتدريب · إصدار 0.1 · 2026-11-10
> الخدمات: رخصة ترميم (5) + تقرير سلامة (13) — مع خط فاصل حاسم نحو «إضافة وتعديل» (10484 ✅).
> المرجع التفصيلي: `../03-SERVICES/05-Renovation-Permit/`.

## 1. الموقف

هاتف 6 مساءً:

> «معك فهد، عندي فيلا سكنية عمرها 22 سنة في حي الشفا. قشرة الجدران تتساقط، فيه تسريبات من السطح، والباب الأمامي محتاج تغيير. جارِي قال هذا "ترميم بسيط" ما يحتاج شي. صحيح؟»

| الحقل | القيمة |
|---|---|
| العميل | فهد ع. — مالك فرد |
| المبنى | فيلا سكنية قائمة برخصة قائمة ✅ (شرط رسمي لرخصة الترميم) |
| الأعمال المعلنة | تساقط قشور، تسريبات سطح، تغيير باب أمامي |
| خطر التشخيص | «ترميم بسيط» بقول الجار — وقد لا يكون كذلك |

## 2. التشخيص — تطبيق الحد الفاصل الرسمي

التعريف الرسمي الموثق ✅ (بلدي): الترميم = استعادة البناء إلى حالته الجيدة **دون إضافة مكون جديد أو تغيير في عناصر المبنى الإنشائية**.

جدول الفرز لأعمال العميل:
| العمل المطلوب | تصنيفه | المسار |
|---|---|---|
| ترميم قشور/جبس/دهانات | ترميم ميكانيكي 📚 | رخصة ترميم ✅ |
| علاج تسريبات السطح (عزل) | ترميم (لا تغيير إنشائي) | رخصة ترميم ✅ |
| تغيير باب أمامي (نفس الفتحة) | صيانة/ترميم | ضمن الرخصة أو إعفاء حسب البلدية ⚠️ |
| **سقف شرفة ليصبح غرفة** | ❌ ليس ترميماً — إضافة مكون | خدمة «إضافة وتعديل مكونات بناء» 10484 ✅ |
| **إسقاط جدار حامل** | ❌ تغيير إنشائي | دراسة إنشائية + مسار إضافة/تعديل ⚠️ حسب البلدية |

**⚠️ لحظة تعليمية:** في التشخيص الأولي ذكر العميل رغبة قديمة «وأيضاً لو صار السطح غرفة نوم أريح». هنا **قطعنا النطاق فوراً**: طلب الترميم يُقدَّم لحده، ورغبة السطح تُقترح كطلب مستقل تُدرس اشتراطاته — دمجها يعطّل الاثنين.

## 3. التنفيذ (مسار خدمة 5 — الخطوات الرسمية ✅)

1. رخصة بناء قائمة ✅ + تعاقد مع مكتب هندسي ✅ + التعهد بإزالة الأنقاض ✅.
2. المكتب: بيانات + مخططات الترميم المطلوبة (وصف أعمال، حدود التدخل) → رفع الطلب → فاتورة → سداد → إصدار (مدة الخدمة المعلنة 10 أيام ✅).
3. ميدانياً: تنفيذ مع توثيق قبل/بعد، والتزم مقاول صغير بإزالة الأنقاض فوراً (تعهد رسمي).
4. **ما بعد التسليم:** تحديث «حالة المبنى» ذهنياً لدى المكتب: أي طلب مستقبلي (إشغال/فرز/رخص تجارية) سيقارن بأحدث رخصة سارية.

## 4. التكلفة 🧪
رسوم الرخصة ⚠️ (حاسبة بلدي) + أتعاب مكتب (صغيرة نسبياً 💼) + تكلفة أعمال الترميم لدى مقاول تشطيب 💼 (خارج نطاقنا غالباً) + تعقيب + VAT 📚. ما لا يتطلب زيارة ميدانية إلزامية هنا: الموافقة الورقية — لكن توثيق الحالة بالصور يحمي الطرفين 💼.

## 5. لوحة القرارات

| لو | المسار |
|---|---|
| طلب العميل يتضمن إضافة/تغييراً إنشائياً | تحويل فوري إلى 10484/دراسة إنشائية — لا «ترميم مزيّف» |
| المبنى متضرر بنيوياً (تشققات إنشائية) | تقرير سلامة (13) أولاً → ترميم كلي أو هدم |
| لا توجد رخصة بناء أصلاً | لا رخصة ترميم — المسار: معالجة الوضع (خدمة 11) |
| مبنى في نطاق تراثي | اشتراطات خاصة للمنطقة/الهيئات التراثية 📚⚠️ قبل التصميم |
| عميل يريد «ترميماً» لمحل مستأجر | التقديم بموجب رخصة البناء — حالة موثقة رسمياً ✅ |
