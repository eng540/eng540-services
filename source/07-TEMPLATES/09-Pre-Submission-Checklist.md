# قائمة التحقق قبل تقديم أي طلب حكومي (Pre-Submission Checklist)

> بوابة جودة إلزامية قبل الرفع على أي منصة (بلدي/ناجز/أي جهة). قوائم الخدمة الخاصة في `03-SERVICES/*/02-Requirements-Documents.md`.

## 1. الملف والأهلية
- [ ] يوجد توكيل/تفويض يغطي هذا الإجراء تحديداً.
- [ ] بيانات مقدم الطلب مطابقة للهوية.
- [ ] الملكية سليمة (صك/قيود) ولا نزاع معروف.

## 2. المستندات
- [ ] كل مستند إلزامي موجود (قائمة الخدمة) + المشروط بالحالة فُصِل وقرر.
- [ ] الصور واضحة كاملة الحدود، بالصيغ والحجم المقبولين.
- [ ] كل مستند فني بتوقيع ساري ومصنف/مرخص.
- [ ] تواريخ الصلاحية سارية (لا مستند على وشك الانتهاء وقت الفحص).

## 3. البيانات المدخلة
- [ ] رقم الصك/القطعة/المخطط مطابق حرفياً للمستندات.
- [ ] المساحات والإحداثيات متطابقة مع المخرجات المساحية.
- [ ] أغراض الطلب صحيحة (بغرض البناء/الهدم…).

## 4. المال والرسوم
- [ ] الرسوم محسوبة من مصدر رسمي (حاسبة بلدي ✅/الجهة) ومتاحة وسائل السداد.
- [ ] يوجد رصيد/وسيلة سداد لدى العميل — لا فواتير متعثرة.

## 5. جاهزية المتابعة
- [ ] سجل المتابعة (نموذج 05) جاهز: المسؤول، مواعيد المراجعة، تنبيهات المدة.
- [ ] خطة الرد على الملاحظات واضحة (من يعالج النوع الفني/الوثائقي).

**قاعدة:** أي «لا» في الأقسام 1–4 = لا رفع. يُستكمل أولاً ويوثق.
