## أ. التحقق الوثائقي
| البند | النتيجة | ملاحظة |
|---|---|---|
| الصك سليم ومطابق للهوية | ✅/❌ | |
| الصك محدث (بياناته = قيد حديث) | ✅/❌ | إن ❌ → خدمة تحديث الصكوك |
| رقم القطعة والمخطط موجودان ومتطابقان | ✅/❌ | |
| المساحة في الصك = المساحة المعلنة | ✅/❌ | فرق؟ سجّل الرقمين |
| لا قيود/حجوزات معروفة على العقار | ✅/❌ | |
| تفويض/وكالة سارية وموثقة إلكترونياً | ✅/❌/لا يلزم | |
| الملكية مشتركة وموافقات الجمهور متوفرة | ✅/❌/لا يلزم | |
