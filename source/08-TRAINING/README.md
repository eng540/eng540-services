## 1. المراحل الثماني (لكل خدمة)

| المرحلة | ماذا تفعل فيه | ملفات المرجع | بوابة النجاح |
|---|---|---|---|
| 1. الفهم | اقرأ README الخدمة وأعد الشرح بأسلوبك | «النظرة الشاملة لكل خدمة» | شرح بلا خطأ جوهري |
| 2. الأنظمة والجهات | احفظ خريطة الجهات الست والأساس النظامي | «النظرة الشاملة» §الجهات + «الأنظمة واللوائح» | اختبار جهات 10/10 |
| 3. المنصات | امش المسار داخل المنصة (محاكاة) | «خطوات المنصة لكل خدمة» + «أدلة المنصات» | مسار كامل بلا طريق مسدود |
| 4. الإجراءات | تعقب الخطوات الـ25 ومنفذ كل خطوة | «خوارزمية 25 خطوة لكل خدمة» | ترتيب صحيح لحالة معطاة |
| 5. تحليل التنفيذ | اقرأ الحالة العملية وحلل القرارات | «المشكلات والحالات والاختبار لكل خدمة» | 5 قرارات مؤثرة محددة |
| 6. المحاكاة الكاملة | نفّذ حالة من الاستقبال للتسليم | «المحاكاات العملية» + النماذج | ملف معاملة مكتمل |
| 7. الحالة الاستثنائية | عالج ملاحظة/رفض/تعارض عبر شجرة القرار | نفس ملف المشكلات + «النماذج التشغيلية» | حل بالمسار الصحيح + توثيق |
| 8. اختبار الإتقان | امتحن | «الاختبارات النهائية» + اختبار الخدمة | ≥ 80% + قرارات صحيحة |

## 2. طريقة الاستخدام (للمتعلم الذاتي أو المدرب)

1. اختر خدمة واحدة فقط في البداية — التوصية: ابدأ بـ«رخصة البناء» (أم الخدمات).
2. ابنِ «سجل إتقان» شخصياً: صف لكل مرحلة بتاريخ الإتمام ودرجتها.
3. في المحاكاة استخدم بيانات افتراضية كاملة (لا بيانات حقيقية) — راعِ أن تملأ النماذج فعلياً من «النماذج التشغيلية».
4. بعد كل خدمة ثلاث: أعد اختبار الخدمات السابقة (تثبيت).
