## 2. طريقة الاستخدام (للمتعلم الذاتي أو المدرب)

1. اختر خدمة واحدة فقط في البداية — التوصية: ابدأ بـ«رخصة البناء» (أم الخدمات).
2. ابنِ «سجل إتقان» شخصياً: صف لكل مرحلة بتاريخ الإتمام ودرجتها.
3. في المحاكاة استخدم بيانات افتراضية كاملة (لا بيانات حقيقية) — راعِ أن تملأ النماذج فعلياً من `07-TEMPLATES/`.
4. بعد كل خدمة ثلاث: أعد اختبار الخدمات السابقة (تثبيت).
