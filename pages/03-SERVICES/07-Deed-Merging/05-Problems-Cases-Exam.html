#1. جدول المشكلات (14 مشكلة × الأعمدة الإلزامية التسعة)

# وصف المشكلة السبب الجذري كيف تُكشف الأثر المسؤول عن المعالجة الإجراء (الحل) المستندات المطلوبة متى التصعيد متى الإيقاف
1 تفاوت مساحة الحدود المشتركة: طول حد التماس مختلف في الصكين دقة قديمة أو قياسات ميدانية متباعدة وقت الإصدار كشف المطابقة المكتبي (04 §6.2) ثم رفع مساحي توقف الدمج أو دمج بمساحة خاطئة مساح مرخص (قياس) + منسق (تعقيب) رفع توثيقي للحد المشترك → معالجة عبر تحديث الصك (خدمة 2) أو ضبط ضمن مسار الدمج حسب الأمانة ⚠️ تقرير المساح، الصكوك، قرار الدمج حين يرفض مسار التحديث/الدمج البيانات إذا ظهر نزاع جار على الحد → إيقاف + إحالة قانونية
2 الصكوك لورثة/أطراف مختلفين وليس لمالك واحد تركة لم تُقسم أو شراءات متفرقة لم توحد ملكيتها عمود «المالك» في جدول مطابقة الصكوك رفض الدمج إلى صك واحد الورثة/الأطراف (تسوية) + محامٍ عند الحاجة مسار تسوية أولاً (حصر إرث/إقرار ورثة/قسمة أو بيع الموحّد للطرف الآخر) ثم الدمج حصر إرث، إقرار ورثة، وثائق قسمة/بيع عند تعذر اتفاق الورثة → محامٍ مرخص نزاع قضائي قائم → إيقاف حتى حكم
3 صك قديم غير محدث قبل القيد الحالي صك ورقي أو بيانات متغيرة فحص «خدمات التحقق»/مقارنة القيد رفض مباشر — متطلب رسمي: صك «محدث من وزارة العدل» ✅ مالك + منسق (خدمة 2) تحديث الصك أولاً ثم إعادة فحص الدمج الصك القديم + رفع مساحي عند طلب العدل ⚠️ تعثر التحديث في العدل → قنوات 1950 — (مسار معالج دائماً)
4 ملكية مشتركة داخل الصكين (حصص متعددة) ميراث أو شراكة قائمة عمود المالك والحصص تعقيد التقديم (وكيل عن الملاك) ونتيجة دمج بصك متعدد الملاك الوكيل عن الملاك + منسق التقديم بصفة وكيل عن الملاك — النظام يسترجع الوكالات من العدل ✅؛ وتحديد شكل الصك الناتج قبل الطلب ⚠️ وكالات شرعية موثقة لكل الملاك اختلاف آراء الملاك → إجماع أو تسوية أحد الملاك يرفض → لا دمج (إيقاف)
5 استخدام مختلف (قطعة سكنية وأخرى تجارية مثلاً) تغير تمييز بين القطعتين المخطط المعتمد/الخرائط الحضرية ✅ خروج عن نطاق الخدمة «الأراضي السكنية داخل مخطط معتمد» ✅ مالك + بلدية/أمانة التحقق من التمييزين ومعالجة الاستخدام أولاً (اشتراطات بلدية/تعديل) 📚 ⚠️ المخطط، اشتراطات التمييز طلب الأمانة تحديث استخدام → مسارها الخاص استخدام غير نظامي قائم → إيقاف حتى تصحيحه
6 قرار مساحي بغرض خاطئ (تجزئة بدل دمج) التباس منتج «الدمج والتجزئة» الواحد قراءة غرض القرار رفض ربط الطلب مالك/مكتب مفوض خدمة «تعديل قرار مساحي» قبل رخصة ✅ أو إصدار قرار جديد بغرض الدمج القرار القائم، بيانات القطع — —
7 قرار مساحي منتهٍ (> 3 سنوات) مرور الصلاحية الرسمية ✅ تاريخ الإصدار رفض الطلب مالك/مكتب إصدار قرار جديد «لنفس الغرض» ✅ القرار المنتهي — —
8 قطعة وسيطة/شارع بين «المتجاورتين» افتراض تجاور غير صحيح المخطط/الخرائط الحضرية ✅ لا دمج بهذه الصيغة أصلاً منسق (تشخيص) إعادة تشخيص: قد يحتاج الأمر شراء القطعة الوسيطة أو مسار مخطط (خدمة 9) المخطط المعتمد — لا دمج → إعادة توجيه العميل
9 مالك موقوف في إحدى الأمانات مخالفات/توقيفات بلدية فحص حالة المالك قبل الطلب «يتم منعه من استكمال تقديم الطلب» ✅ المالك رفع سبب التوقيف لدى الأمانة ثم إعادة التقديم تفاصيل التوقيف، مستندات المعالجة رفض الأمانة الرفع → قنوات 199040 توقيف غير قابل للمعالجة قصيرة المدى → إيقاف
10 حجز أو نزاع على أحد الصكوك قضية/توقيف سجلي فحص ناجز ⚠️ + استبيان العميل إيقاف شامل محامٍ مرخص معالجة قضائية أولًا؛ لا يُرفع أي طلب المستندات القضائية ⚠️ فوراً عند الكشف طوال عمر الحجز/النزاع
11 رفض أو ملاحظة بلدية على الطلب مرفق ناقص/بيانات متعارضة/اشتراط أمانة حالة الطلب في «طلباتي» ✅ تعليق الطلب منسق + مكتب مفوض قراءة سبب الملاحظة → ردّها بمستند صحيح (خطوة 18 من 03) الملاحظة + المستند المجيب ملاحظة متكررة غير محسومة → شكوى 199040 (استجابة 24 ساعة ✅) رفض قطعي مسبب → دراسة مسار بديل
12 جوال غير مرتبط بأبشر / بيانات دخول غير صحيحة جوال قديم أو غير مسجل محاولة B1 ✅ توقف عند أول خطوة العميل تحديث الجوال في أبشر ثم إعادة الدخول — — —
13 وكالة لا تغطي التصرف المطلوب وكالة ضيقة (بيع فقط مثلاً) تدقيق نص الوكالة رفض التمثيل أو اعتراض لاحق المالك (إصدار وكالة أدق) إصدار وكالة موثقة تشمل التقديم على الجهات/إتمام الدمج ⚠️ الوكالة الجديدة — انتهاء وكالة منتصف المعاملة → توقف حتى تجديدها
14 عقار داخل نطاق السجل العقاري توسع مرحلي للتسجيل العيني سؤال النطاق/الاستعلامات 📚 ⚠️ مسار الصك التقليدي لا يكفي منسق + الهيئة العامة للعقار اعتماد مسار القيد السجلي: الدمج/التوحيد يتبع بيانات القيد 📚 ⚠️ بيانات القيد تعارض القيد مع الصكوك → قنوات الهيئة خلاف قيدي قائم → إيقاف لحسمه

#2. شجرة القرار النصية (تتفرع حسب السبب — لا حل موحد)

ابدأ: طلب دمج صكوك
│
├─ هل الصكوك إلكترونية سارية محدثة من العدل؟
│   ├─ لا ──→ [خدمة 2: تحديث الصكوك] ──→ عُد لبداية الشجرة
│   └─ نعم ↓
│
├─ هل على أي صك حجز/نزاع/توقيف سجلي؟
│   ├─ نعم ──→ إيقاف ──→ محامٍ مرخص ──→ عُد بعد الحسم
│   └─ لا ↓
│
├─ هل المالك موقوف في إحدى الأمانات؟
│   ├─ نعم ✅ ──→ معالجة التوقيف لدى الأمانة ──→ عُد
│   └─ لا ↓
│
├─ من المالكون في الصكوك؟
│   ├─ مالك واحد (أو نفس المالك في كل الصكوك) ──→ تابع ↓
│   ├─ ورثة/أطراف مختلفون ──→ مسار التسوية (حصر إرث/قسمة/بيع موحّد)
│   │        └─ عُد بعد اكتمال التسوية
│   └─ ملكية مشتركة مقصودة ──→ وكيل عن الملاك (استرجاع من العدل ✅) ──→ تابع ↓
│
├─ هل القطع متجاورة فعلاً (لا شارع/قطعة وسيطة)؟
│   ├─ لا ──→ لا دمج ──→ إعادة تشخيص (شراء الوسيطة؟ خدمة 9؟) 
│   └─ نعم ↓
│
├─ هل القطع سكنية داخل مخطط معتمد بنفس التمييز؟
│   ├─ لا/مختلف ──→ تحقق الاستخدام مع الأمانة 📚⚠️ ──→ عالج ثم تابع
│   └─ نعم ↓
│
├─ هل حدود التماس متسقة بين الصكين؟
│   ├─ شك/تفاوت ──→ رفع مساحي (مساح مرخص) ──→
│   │        ├─ فرق طفيف مقبول ──→ تابع ↓
│   │        └─ فرق جوهري ──→ خدمة 2 (تحديث) ──→ عُد
│   └─ متسقة ──→ تابع ↓
│
├─ هل القرار المساحي بغرض «دمج الأراضي» وسارٍ (≤3 سنوات)؟
│   ├─ بغرض آخر ──→ تعديل قرار ✅ أو قرار جديد
│   ├─ منتهٍ ──→ قرار جديد بنفس الغرض ✅
│   └─ نعم ↓
│
├─ الطلب في بلدي (LMS) — الملاحظات؟
│   ├─ ملاحظة ──→ عالج بمستند الصحيح ──→ أعد الإرسال
│   └─ اعتماد/مخرج بلدي ↓
│
├─ هل الغرض يتطلب صكاً موحداً؟
│   ├─ نعم ──→ ناجز: دمج توثيقي ⚠️ ──→ صك موحد ──→ تحقق ✅
│   │        └─ داخل نطاق السجل العقاري؟ ── نعم ──→ مسار قيدي 📚⚠️
│   └─ لا (تنظيم مخطط فقط) ──→ أرشف المخرج البلدي
│
└─ خطوة تالية: قرار مساحي جديد على الوحدة الموحدة ✅ ──→ رخصة بناء (خدمة 1) أو غيرها

قاعدة التصعيد العامة لكل المشكلات: مشكلة مستندية/إدارية → المنسق يملكها؛ مشكلة مساحية → المساح المرخص؛ مشكلة ملكية/قانونية → محامٍ مرخص؛ مشكلة اعتماد → الجهة الحكومية بقنواتها الرسمية (1950 للعدل، 199040 لبلدي ✅). المكتب لا يتصرف بصفة أي من هؤلاء.

#3. أسئلة الاستقبال التشخيصية (تُطرح على كل عميل دمج قبل أي التزام)

عشرة أسئلة تفصل 80% من المشكلات قبل حدوثها 📚 — أجوبتها تملأ جدول المطابقة وتحدد فرع شجرة القرار مبكراً.

# السؤال ماذا يكشف
1 كم صكاً لديك ولمن المسجَّل في كل واحد منها؟ مشكلة 2 و4 (ورثة/مشتركون)
2 هل الصكوك إلكترونية محدثة من العدل؟ مشكلة 3 (تحديث أولاً)
3 هل بين القطعتين شارع أو قطعة وسيطة؟ مشكلة 8 (لا دمج)
4 ما تمييز كل قطعة في المخطط (سكني/غيره)؟ مشكلة 5 (استخدام مختلف)
5 هل لديك أي قضية أو حجز أو مخالفة أمانة قائمة باسمك؟ مشكلة 9 و10 (توقيف/حجز)
6 هل خُطت حدود القطعتين وتوجد سياج/أثر بناء على الفرق؟ حاجة الرفع المساحي
7 هل لديك قرار مساحي حالي وبأي غرض؟ مشكلة 6 و7
8 من سيقدّم الطلب: أنت أم وكيل؟ (رقم الوكالة؟) صفة التقديم والتوكيلات
9 هل الموقع مسيج أو مشغول؟ (لتنسيق أي زيارة) بروتوكول الزيارة 04 §7
10 ما الهدف النهائي بعد الدمج: بناء/بيع/تمويل؟ المسار اللاحق (رخصة/بيع/سجل) والفرص

#4. بطاقات فحص سريع للمشكلات الأكثر تكراراً

  ├─ فرق ≤ هامش مقبول للأمانة (يتحقق من الأمانة ⚠️) ──→ وثّق وتابع
  └─ فرق جوهري ──→ رفع مساحي (مساح مرخص) ──→
        ├─ بيانات واقع مطابقة للقيد ──→ حدّث الصك (خدمة 2) ثم ادمج
        └─ تضارب يفتح خلاف جار ──→ إيقاف + محامٍ

بطاقة «الصكوك لورثة مختلفين» (مشكلة 2):

افحص: أسماء الملاك في كل صك
  ├─ نفس المالك ──→ مسار قياسي
  ├─ ورثة غير مسقين ──→ تسوية (حصر/قسمة/إقرار) ──→ صك محدث باسم موحّد ──→ دمج
  └─ أطراف غير أقارب ──→ بيع موحّد موثق (ناجز) ──→ دمج
قاعدة: لا دمج قبل «نفس المالك» — لا استثناءات إجرائية 📚

بطاقة «الطلب معلق في بلدي» (مشكلة 11):

افحص: حالة الطلب في «طلباتي» ✅
  ├─ دفع معلق ──→ سداد فوري (قناة سداد ✅)
  ├─ جاري العمل عليها (أكثر من 10 أيام ✅ المدة المعلنة) ──→ استعلام دعم 199040
  └─ ملاحظة ظاهرة ──→ عالجها (بطاقة المطابقة أعلاه) ──→ أعد الإرسال

#5. الحالتان العمليتان 🧪

البيانات افتراضية بالكامل للتدريب (أسماء وأرقام ومساحات 🧪). كل خطوة إجرائية تعكس ما هو موثق ✅ أو موسوم ⚠️/📚.

الحالة الأولى (سلسة): صكّان متلاصقان لمالك واحد — بناء موحد

البيانات: أبو عبدالله يملك قطعتين متجاورتين في مخطط سكني معتمد: قطعة (44) 625 م² وقطعة (45) 625 م²، صكّان إلكترونيان محدثان باسمه، لا نزاع، المالك غير موقوف، يريد بناء فيلا موحدة على 1250 م².

  1. استقبال وتشخيص: الغرض «بناء موحّد» — دمج صحيح (توحيد وليس تجزئة). جُمعت الصكوك ونسخت إحداثياتهما؛ حد التماس (الشرقي/الغربي بين 44 و45) متطابق في الصكين (25 م في كليهما). [خطوات 1–5]
  2. قرار ميداني: لا رفع مساحي — التلاصق مؤكد بالبيانات والمخطط والقرار المساحي صادر بغرض «دمج الأراضي» يشمل القطعتين (صادر قبل شهر — ساري ضمن 3 سنوات ✅). وُثق القرار في الملف. [خطوة 6 بلا انطباق للخطوة 7]
  3. الصفة والتجهيز: تقديم المالك عن نفسه؛ جواله مرتبط بأبشر؛ تعهد الملكية جاهز؛ مرفقات الأمانة المسجلة في القرار مكتملة ✅؛ اختار مكتباً هندسياً مصنفاً وعرض بلدي بيانات تواصله ✅. [خطوات 11–15]
  4. الرفع في بلدي: طريقة التقديم الرسمية B1→B5 ✅ — صدر رقم طلب يبدأ بـ LMS ✅. [خطوة 16]
  5. المتابعة: بعد 4 أيام 🧪 حالة «طلب بانتظار إصدار الصك/الصكوك» (من حالات «طلباتي» الرسمية ✅)؛ ثم طلب سداد — سُدد عبر قناة سداد ✅. [خطوات 17–19]
  6. النتيجة البلدية: الطلب «مكتمل-تم الحل» — استُخرج مخرج الدمج: القطعتان موحدة (1250 م² 🧪) في المخطط. [خطوة 20]
  7. التوثيق: عبر ناجز استُكمل الدمج التوثيقي ⚠️ (المسار الحي) وصدر صك إلكتروني موحد لمساحة مجمعة باسمه؛ تحقق المنسق منه عبر «خدمات التحقق» ✅ (بنية) — المساحة والإحداثيات مطابقة للمخرج البلدي. [خطوات 21–23]
  8. البوابة التالية: طلب قرار مساحي جديد بغرض البناء على الوحدة الموحدة ✅ (القاعدة الرسمية: دمج أولاً ثم قرار جديد)، ثم يفتح ملف رخصة بناء (خدمة 1) بارتفاع اشتراطات محسوبة مرة واحدة على 1250 م². [خطوة 24]
  9. الإقفال: تسليم الحزمة (الصك الموحد، المخرج البلدي، إثبات السداد، رقم LMS) + أرشفة الصكين القديمين. [خطوة 25]

دروس الحالة: الدمج السلس = صكوك محدثة + قرار بغرض صحيح + تلاصق نظيف + متابعة «طلباتي» يومية.

خط زمني توضيحي للحالة الأولى 🧪 (للتدريب فقط — ليس مدداً رسمية):

اليوم 🧪 الحدث
1–2 استقبال + جمع الصكوك + فحص ناجز + جدول المطابقة
3 قرار «لا رفع مساحي» + تجهيز الصفة والمرفقات + اختيار المكتب
4 رفع الطلب — رقم LMS
5–9 متابعة؛ طلب سداد يوم 7 وسُدد
10–12 حالة «مكتمل-تم الحل» + مخرج بلدي
13–18 🧪 مسار ناجز للصك الموحد ⚠️ (مدة غير معلنة رسمياً)
19 تحقق من الصك + تسليم + توصية قرار مساحي جديد

الحالة الثانية (استثنائية): صكوك متلاصقة لورثة مختلفين — التسوية قبل الدمج

البيانات 🧪: تركة الأستاذ سالم: قطعة (70) صك باسمه (ورثه 3 أبناء) وقطعة (71) صك أصدر بعد وفاة باسم ابنه الأكبر مباشرة (وصلت تركة منفصلة). القطعتان متجاورتان 500 م² لكل منهما. يريد الورثة «وحدة واحدة ثم بيعها».

  1. اكتشاف المشكلة مبكراً: في جدول المطابقة — المالك في صك (70) «وارثو سالم (3 أبناء)» وفي صك (71) «الابن الأكبر». ليست ملكية واحدة — مشكلة رقم 2 من الجدول. [خطوتا 2–4]
  2. قرار التصنيف: لا يُرفع أي طلب دمج الآن. المخرج المطلوب «صك واحد» لا يتأتى إلا بتوحيد الملكية أولاً. [خطوة 4 — بوابة شجرة القرار]
  3. مسار التسوية (إحالة قانونية): للورثة ثلاثة مسارات استشارية 📚: (أ) قسمة تركة القطعة 70 بين الورثة ثم شراء/تنازل لصالح تركيب ملكية واحدة؛ (ب) بيع ملكية الورثة في القطعتين لطرف واحد ثم دمجه؛ (ج) اتفاق على بيع العقارين موحدين عبر إجراءات التركة. المنسق يوثق الخيارات ويحيل إلى محامٍ/موثق لحسم الأنسب — لا يتولى بنفسه حسم التركات (حدود الأدوار).
  4. ما يُنفذ بالتوازي دون التسوية: فحص صحة الصكين ⚠️، تأكيد التلاصق بالمخطط، التأكد من عدم وجود حجز على التركة، تحضير كل ما لا يعتمد على شكل الملكية النهائي. [خطوات 3، 5، 10]
  5. بعد اكتمال التسوية 🧪 (فرضية): اختار الورثة المسار (أ): صدر لصك (70) تحديث بعد القسمة أصبح فيه الابن الأكبر مالكاً 100%، وباع الورثة الآخرون حصصهم موثقة في ناجز — الآن «نفس المالك» في الصكين. [خطوة 9 منطقها نفسه: توحيد قبل الدمج]
  6. استئناف المسار القياسي: فحص الحدود المشتركة (وجد تفاوت 0.4 م 🧪 بين قيدين قديمين) → رفع مساحي توثيقي من مساح مرخص → فرق طفيف مقبول للمعالجة ضمن مسار الدمج حسب الأمانة ⚠️. [خطوات 5–9]
  7. الدمج: قرار مساحي بغرض «دمج الأراضي» على القطعتين ✅ → طلب بلدي LMS ✅ → ملاحظة أمانة وحيدة طُلبت فيها صورة وثيقة القسمة (من مرفقات الأمانة المتغيرة ✅/⚠️) → رُفعت واعتُمد → مخرج بلدي → صك موحد في ناجز ⚠️ → تحقق ✅. [خطوات 15–23]
  8. الإقفال: بيع الوحدة الموحدة أو البناء — يفتح الملف الخدمة التالية. [خطوات 24–25]

دروس الحالة: «دمج الصكوك» شرطه الملكية لا الجوار فقط؛ ورثة مختلفون = مشروع تسوية قبل أن يكون مشروع دمج؛ والمرفقات تتبع الأمانة المسجلة في القرار — جهّز وثائق التسوية مع الطلب ✅.

خط زمني توضيحي للحالة الثانية 🧪:

اليوم 🧪 الحدث
1–2 استقبال + جدول المطابقة يكشف اختلاف الملاك (ورثة)
3 توقف مسار الدمج + عرض خيارات التسوية الثلاثة + إحالة قانونية
4–25 🧪 مسار التسوية (خارج سيطرة المكتب — مدد غير رسمية ⚠️)؛ بالتوازي: فحص التلاصق والتأكد من خلو التركة من حجز
26 اكتمال التسوية 🧪: صك (70) محدث باسم المالك الموحد

29 رفع LMS ✅

#6. اختبار الإتقان (10 أسئلة: 6 معرفة + 4 قرار)

التعليمات: أجب دون الرجوع للملفات ثم قارن بالمفتاح. النجاح: 8/10 (80%).

  1. (معرفة) ما الفرق الجوهري في «اتجاه العمل» بين خدمة دمج الصكوك (7) وخدمة فرز الوحدات (3)؟
  2. (معرفة) اذكر المخرج الرسمي المتوقع في كل مستوى من مستويي الدمج: البلدي والتوثيقي، والجهة المالكة لكل منهما.
  3. (معرفة) ما هو متطلب «القرار المساحي» في خدمة الدمج، وما مدة صلاحيته الرسمية، وماذا لو كان الغرض «تجزئة» بالخطأ؟
  4. (معرفة) وفق النص الرسمي في بلدي: هل يوجد حد أدنى للمساحة في الدمج؟ وما المقابل في التجزئة؟
  5. (معرفة) بأي حرف يبدأ رقم طلب الدمج في بلدي؟ واذكر ثلاث حالات من حالات المتابعة الرسمية في «طلباتي».
  6. (معرفة) في أي حالة رسمية يُمنع المالك من استكمال تقديم طلب الدمج؟
  7. (قرار) عميل لديه قطعتان متجاورتان: صك واحدة باسمه وصك الأخرى باسم والده المتوفى (لم تُقسم تركة). ما أول إجراء؟ ولماذا لا نرفع طلب الدمج الآن؟
  8. (قرار) مالك يريد دمج قطعتيه وقد صدر له قرار مساحي بغرض «تجزئة الأراضي» منذ شهر. قدم الحل الإجرائي الكامل دون فقدان استحقاقه.
  9. (قرار) طلب دمج في بلدي عاد بملاحظة «مرفق مساحي غير مطابق للحدود المشتركة». صف خطوات المعالجة بالترتيب والمنفذين.
  10. (قرار) عميل يقول: «أتعبوني بدمجي ولم يصدر صك موحد حتى الآن بعد اكتمال الطلب في بلدي». شخّص السبب الأرجح وصحح توقعه بالمسار الصحيح.

#7. مفتاح الإجابات

  1. الاتجاه معاكس تماماً: الدمج يوحّد صكوكاً/قطعاً قائمة في وحدة واحدة؛ الفرز يقسّم صكاً واحداً إلى صكوك مستقلة للوحدات. (جدول المقارنة في README §10).
  2. البلدي: قطعة موحدة على مستوى المخطط/المخرج البلدي — الجهة: الأمانة/البلدية عبر بلدي (منتج «خدمات الدمج والتجزئة» ✅). التوثيقي: صك إلكتروني موحد — الجهة: وزارة العدل/ناجز (المسار الداخلي ⚠️).
  3. متطلب رسمي ✅: قرار مساحي «الغرض منه (دمج الأراضي)»؛ صلاحيته 3 سنوات ✅؛ إن كان بغرض تجزئة: تُستخدم خدمة «تعديل قرار مساحي» ✅ قبل الربط أو يصدر قرار جديد بالغرض الصحيح.
  4. الدمج: «لا توجد مساحة محددة لدمج قطع الأراضي المتجاورة» ✅. التجزئة: لا تقل مساحة القطعة عن 400 م² قبل التجزئة ✅.
  5. يبدأ بـ LMS ✅ (والتجزئة LSA). أي ثلاث من: جاري العمل عليها / طلبات الدفع المعلقة / بانتظار إصدار الصك/الصكوك / مكتملة-تم الحل / تم التراجع ✅.
  6. موقوف المالك في إحدى الأمانات → «يتم منعه من استكمال تقديم الطلب» ✅.
  7. أول إجراء: مسار التسوية قبل الدمج (ملكية مختلفة = مشكلة 2): حصر إرث/قسمة/تسوية لإخراج ملكية واحدة (إحالة قانونية عند الحاجة). لا يُرفع طلب الدمج لأن شرط «الملكية نفسها» غير مستوفى، والدمج يوقف ويعترض عليه القيد ⚠️.
  8. الغرض خاطئ والقرار سارٍ: الحل هو خدمة «تعديل قرار مساحي» ✅ (مسموح قبل إصدار رخصة على القرار) لتغيير الغرض إلى «دمج الأراضي»، أو إصدار قرار جديد بغرض الدمج؛ ثم ربطه في طلب بلدي. لا يُرفع الطلب على قرار بغرض تجزئة.
  9. (1) قراءة سبب الملاحظة من داخل الطلب؛ (2) تحديد المنفذ الفني: مساح مرخص يعيد/يوثق الحدود المشتركة (رفع)؛ (3) مطابقة النتيجة مع بيانات الصكوك — إن كان فرق جوهرياً: خدمة 2 تحديث الصكوك أولاً (القاعدة: أحدث الصكوك أولاً)؛ (4) رد الملاحظة بالمستند الصحيح من صاحب الصلاحية (المنسق يعقّب، المساح يوقع، لا اعتماداً لغير الجهة)؛ (5) متابعة حتى الاعتماد — وإن تكررت الرفض: قناة 199040 (استجابة 24 ساعة ✅).
  10. السبب الأرجح: اكتمل الدمج البلدي فقط (وحدة المخطط) — والمخرج البلدي ليس صكاً؛ الصك الموحد يصدر من وزارة العدل عبر ناجز (والجواب الرسمي يؤكد التوجه للعدل لإصدار الصك ✅). التصحيح: استكمال الدمج التوثيقي/إصدار الصك في ناجز ⚠️ ثم التحقق ✅.
