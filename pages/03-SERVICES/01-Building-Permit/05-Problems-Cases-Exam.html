#1. جدول المشكلات (13 مشكلة × الأعمدة التسعة)

الاختصارات: ن=منسق · ص=مكتب مصمم · س=مساح · ق=مقاول · ش=مشرف · ف=فاحص فني · ب=أمانة · م=مالك.

# وصف المشكلة السبب الجذري كيفية الكشف الأثر المسؤول الإجراء/الحل المستندات المطلوبة متى التصعيد متى الإيقاف
1 صك غير محدث أو بياناته متفاوتة (مساحة/حدود/ملاك) صك قديم أو وراثة غير مكتملة جلب حي للصك داخل بلدي ومطابقته للقطعة ✅ لا يمكن استيفاء المتطلب 1؛ توقف قبل البدء ن (كشف) + م (علاج) تحويل لخدمة 2 (تحديث الصكوك) — وقد تشمل رفعاً مساحياً (خدمة 8) صك حالي، هوية، بيانات ورثة إن وجدت فور اكتشاف تفاوت البيانات حتى يصدر صك محدث متطابق
2 لا قرار مساحي بغرض البناء عدم استخراجه سلفاً أو قرار قائم بغرض آخر الاستعلام في بلدي/قائمة أرقام القرارات الظاهرة للمستفيد ✅ المتطلب 2 غير مستوفى؛ شاشة الطلب تمنح مسار أ بديلاً ن + س خدمة 4 أولاً، أو المسار أ (إصدار القرار من خلال المكتب الهندسي) ✅ بيانات القطعة، صك محدث إذا احتاج قرار رفعاً مساحياً جديداً حتى صدور قرار بغرض البناء
3 مكتب مصمم غير معتمد/حسابه غير جاهز في بلدي أعمال اختيار عشوائي أو مكتب بلا تصنيف سارٍ قوائم المكاتب المعتمدة في بلدي ✅ لا يمكن قبول التفويض؛ توقف المسار منذ خطوته الأولى م (اختيار) استبدال المكتب بمعتمد لدى الوزارة ✅ تصنيف المكتب من الهيئة السعودية للمهندسين ⚠️ عند فشل قبول التفويض أكثر من مرة حتى يقبل مكتب معتمد
4 مخالفة بلدية قائمة على العقار بناء سابق دون رخصة/تجاوز اشتراطات استعلام بلدي/التشخيص الميداني قد تعلّق الطلبات وتفرض غرامات وفق لائحة الغرامات ✅ م (ملكية المسؤولية) تقييم: تصحيح وضع مبنى (خدمة 11) أو تقرير سلامة (13) قبل متابعة الرخصة صور الموقع، إشعار المخالفة إن وجد عند وجود إشعار رسمي بالغرامة حتى تُعالج المخالفة أو تُصعَّد لمسار معالجة
5 تصميم مخالف لاشتراطات القطعة (ارتداد/نسبة/ارتفاع/مواقف) التصميم قبل تثبيت الاشتراطات أو على قيم مسموعة 📚 جدول مطابقة داخلي قبل الرفع ملاحظات من ف/ب؛ إعادة تصميم وتأخير ص (تصميم) تعديل التصميم على الاشتراطات المثبتة؛ ⚠️ القيم حسب البلدية والتمييز فقط اشتراطات القطعة المثبتة، المخططات عند تعارض الاشتراط نفسه بين مصدرين رسميين حتى يطابق التصميم اشتراطاً مثبتاً كتابياً
6 ملاحظات الفاحص الفني المتكررة (إنشائية) تفاصيل غير مطابقة لكود البناء السعودي ✅؛ تصميم دون تربة سليمة رسائل الملاحظات داخل الطلب دورات إعادة؛ تأخير أسابيع؛ تآكل ثقة العميل ص خطة معالجة: كل ملاحظة بربطها ببند كود + مخطط معدل؛ إن لزم مراجعة تربة سجل الملاحظات، المخططات المعدلة، تقرير التربة بعد دورتين بلا تقارب (حالة ب أدناه) عند اعتماد الفاحص
7 تأخر اعتماد الأمانة بلا ملاحظات ظاهرة ضغط عمل البلدية/نقص مراجعين متابعة «إدارة الطلبات» ومراقبة الحالة ✅ تأخير الاعتماد وشهادة التصاميم ب (جهة) — ن (تعقب) متابعة منتظمة عبر المنصة + استفسار رسمي عبر قنوات الدعم الموثقة ⚠️ رقم الطلب، لقطات حالة بعد تجاوز المدة المعلنة في اتفاقية مستوى الخدمة ⚠️ عند صدور الاعتماد
8 موافقة جهة خارجية معلقة (مرورية/دفاع مدني/طاقة) نشاط يستلزمها (اشتراط رسمي 3 ✅) مراجعة شروط النشاط قبل التقديم توقف الاعتماد على جهة خارج المنصة خ (جهة) — ن (تعقب) إدراجها مبكراً في الجدول؛ تجهيز مخططات الجهة؛ متابعة قنواتها الرسمية ⚠️ مخططات الجهة، طلب الموافقة عند تجاوز المهلة المتفق عليها مع العميل 💼 حتى صدور الموافقة أو تعديل النشاط
9 مقاول غير مصنف أو يرفض الإسناد مفضل مالك غير مسجل/مقاول متردد قوائم المقاولين المصنفين في بلدي ✅ (شرط رسمي) توقف مرحلة التعاقدات ✅ م + ق اختيار مقاول مصنف ✅ أو تفعيل تسجيل المفضل لدى الوزارة ⚠️ تصنيف المقاول عند رفض الإسناد النهائي حتى يوافق مقاول مصنف
10 مشرف لا يقبل الإسناد عدم توافقه/تعارض مصالح إشعار القبول داخل المنصة ✅ توقف التعاقدات (المشرف سلف المقاول في المسار ✅) ش اختيار مشرف بديل موافقة المشرف عند رفض واضح حتى يقبل مشرف
11 سُددت رسوم الرخصة دون وثيقة التأمين سوء تفسير «الإصدار بعد السداد» حالة الرخصة «غير سارية» وعدم امكانية الطباعة ✅ (نص رسمي) رخصة صادرة غير سارية — لا تصلح للتعامل ن (تعقب) + م (سداد) سداد قسط الوثيقة عبر رابطها الآلي فوراً ثم التحقق من السريان إيصال الرسوم، وثيقة التأمين فور اكتشاف الحالة غير السارية عند تحول الحالة إلى سارية ✅
12 انتهاء صلاحية فاتورة الرسوم أو تأخر السداد مهلة الفاتورة ⚠️/تأخر العميل مراقبة الفاتورة في الطلب إعادة إصدار فاتورة وتأخير م إعادة إصدار وسداد في مهلتها ⚠️ الفاتورة قرب انتهاء المهلة 💼 عند السداد
13 بيانات المخطط/القطعة في الطلب لا تطابق الصك (رقم قطعة/مخطط/مساحة) خطأ إدخال أو صك متقدم على اعتماد المخطط مطابقة آلية عند اختيار القرار المساحي ✅ + مراجعة بشرية للن رفض أو تعليق؛ قد يكشف مشكلة صك أعمق ن (إدخال) تصحيح الإدخال؛ إن كان الجذر في الصك → خدمة 2 صك، قرار مساحي، بيانات المخطط عند فشل التصحيح الإداري عند اكتمال المطابقة

#2. شجرة قرار التعثر/الرفض (تتفرع حسب السبب — لا حل موحد)

المعاملة متعثرة أو مرفوضة؟
│
├─ 1. في أي مرحلة وقف؟
│   ├─ قبل بدء الطلب → نواقص سلف (تابع فرع 2)
│   ├─ بعد الإرسال عند الفحص الفني → تابع فرع 3
│   ├─ عند الأمانة → تابع فرع 4
│   ├─ عند الجهات الخارجية → تابع فرع 5
│   ├─ في التعاقدات → تابع فرع 6
│   └─ عند التأمين/الرسوم/الإصدار → تابع فرع 7
│
├─ 2. نواقص سلف:
│   ├─ صك → خدمة 2 (تحديث الصكوك) ثم عُد
│   ├─ قرار مساحي → خدمة 4 أو المسار أ داخل الخدمة ✅
│   ├─ دراسة تربة → مختبر جيوتقني (قبل التصميم الإنشائي دائماً)
│   ├─ تفويض → تحديث التفويض البلدي/الوكالة
│   └─ مخالفات قائمة → تصعيد: خدمات 11/13 (تصحيح وضع/سلامة) قبل المتابعة
│
├─ 3. ملاحظة فاحص فني (ف):
│   ├─ بند كود واضح → معالجة هندسية بالمكتب المصمم + إعادة إرسال
│   ├─ ملاحظة تعارض مع اشتراط بلدي → استفسار رسمي موحد قبل التعديل
│   └─ دورة متكررة (>2) → اجتماع فني مصلَّح + مراجعة كاملة للحزمة (حالة ب)
│
├─ 4. ملاحظة أمانة (ب):
│   ├─ اشتراط قطعة → تعديل التصميم على الاشتراط المثبت ⚠️ (حسب البلدية/التمييز)
│   ├─ ملاحظة إدارية → استكمال مستند/تصحيح بيانات
│   └─ ملاحظة نظامية خلافية → اعتراض عبر منصة الاعتراضات الموحدة ✅ (منتج رسمي) أو استفسار رسمي
│
├─ 5. جهة خارجية (خ):
│   ├─ مطلوب مستند إضافي → استيفاؤه من المالك/المكتب
│   ├─ موافقة مرفوضة → مراجعة سبب الرفض: تعديل التصميم أو مسار بديل رسمي
│   └─ تأخير → تصعيد زمني للعميل بجدول واقعي 💼
│
├─ 6. تعاقدات:
│   ├─ مقاول غير مصنف → استبدال بمصنف ✅ (شرط رسمي)
│   ├─ رفض مشرف/مقاول → بديل
│   └─ تأخر رد → تنبيه نصي عبر المنصة + متابعة
│
└─ 7. تأمين/رسوم/إصدار:
    ├─ رخصة غير سارية → سداد قسط الوثيقة (الربط الآلي ✅) ثم التحقق
    ├─ فاتورة منتهية → إعادة إصدار وسداد ⚠️
    └─ بيانات رخصة خاطئة → تصحيح قبل الطباعة عبر الطلب ⚠️

قواعد القرار الثلاث: 1. حدد الطبقة أولاً (مستندات/مساحية/فني/بلدي/خارجي/مالي) ثم عالج في طبقتها — لا تعالج ملاحظة أمانة بتعديل إنشائي ولا العكس. 2. الاعتراض الرسمي مسار مشروع عبر منصة الاعتراضات الموحدة ✅ — وليس إعادة تقديم لنفس الطلب نفسه. 3. أي توقف بلا مرسل إليه > مهلة متفق مع العميل 💼 → تصعيد موثق (تقرير حالة للمالك).

#3. الحالة العملية ① — مسار سلس 🧪

🧪 بيانات افتراضية للتدريب (2026-11-10). الشخصيات: م.عبدالله مالك، مكتب «X» مصمم، مختبر «ج» جيوتقني، مقاول «ق1» مصنف.

المعطيات: أرض سكنية 400م²، قطعة 42/مخطط 5، صك إلكتروني محدث مطابق، قرار مساحي بغرض البناء صادر (ظهر ضمن أرقامه في بلدي ✅)، دراسة تربة حديثة تقبل بصات، يريد عمارة 3 أدوار (دور علوي واحد/أسفل ورديسة).

المسار: 1. يوم 1–2: المنسق يفحص الصك (مطابق ✅) والقرار (بغرض البناء ✅) — لا مخالفات ظاهرة في الاستعلام. عرض سعر: أتعاب تصميم 15,000 + إنشائي 10,000 + تعقيب 4,000 + تربة 0 (جاهزة) 🧪 + رسوم حكومية «من الحاسبة» ⚠️ + VAT 📚. يوقّع الاتفاقية. 2. يوم 3: م.عبدالله يصدر التفويض البلدي الإلكتروني لمكتب X ✅؛ يبدأ الطلب من حسابه (تقديم جديد ← طلب إصدار ← الرخص الإنشائية ← إصدار رخصة بناء ✅)، يختار المسار ب (قراره المساحي من القائمة ✅)، المسار الاعتيادي، يكتب ملاحظاته الموجهة للمكتب، يرفع مرفقاته، «تم إرسال الطلب إلى المكتب الهندسي» ✅. 3. يوم 4–18: مكتب X يقبل التفويض، يحدد القرار المساحي، يعمل التصميم المعماري (جدول مطابقة: ارتدادات/نسبة/ارتفاع كلها مطابقة ✅) والإنشائي على تقرير «ج» (بصات عادية)، جدول مساحات، رفع الحزمة + الموافقة على التعهدات البلدية ✅. 4. يوم 19: إسناد آلي لشركة الفحص الفني ✅ — ملاحظتان (تفصيلة فتحة تهوية + رمز مادة في ورقة إنشائية)؛ يعالجهما المكتب في يومين ويعيد الإرسال. 5. يوم 24: اجتياز الفحص → الأمانة تراجع — بلا ملاحظات → اعتماد + شهادة اعتماد التصاميم ✅ (يطبعها المكتب). 6. يوم 25: إشعار مرحلة التعاقدات ✅ — المكتب المصمم يحدد المشرف «ش1» (يوافق) ثم المقاول «ق1» المصنف (يوافق + يكمل بياناته ومرفقاته لإرسالها لشركة التأمين ✅). 7. يوم 26–28: نظام بلدي يرسل طلب الوثيقة آلياً ✅ → رابط سداد القسط → م.عبدالله يسدد → وثيقة صادرة. المكتب يوافق على رسوم الرخصة ويصدر الفاتورة ✅ (المبلغ من الحاسبة/الفاتورة ⚠️) → سداد بنفس الفترة. 8. يوم 29: إصدار الرخصة — الحالة سارية ✅، طباعتها، إشعار الجهات آلياً (كهرباء/مياه/طاقة/دفاع مدني/تأمين/سجل عيني ✅). 9. يوم 30: تسليم موثق: PDF الرخصة + الوثيقة + شهادة اعتماد التصاميم، ملف مؤرشف برقم الطلب، وفتح فرص: عقد إشراف «ش1» + جدول إشعارات البناء + موعد شهادة إشغال بعد الإنجاز (خدمة 6) + فرز الوحدات لاحقاً (خدمة 3).

دروس الحالة: اكتمال السلف قبل الطلب جعل الدورة الكاملة ~شهراً 🧪 بملاحظة واحدة فقط من كل طبقة؛ والتسلسل الصحيح (تربة ← إنشائي) منع أي إعادة.

#4. الحالة العملية ② — حالة استثنائية مركبة 🧪

🧪 بيانات افتراضية للتدريب. م.سعاد وريثة مع شقيقها، صك ورثة قديم، تصميم متعثر بملاحظات متكررة.

المعطيات: قطعة سكنية 300م²، صك ملكية صدر قبل سنوات بأسماء الورثة الثلاثة (الأب توفّي) بلا توثيق حصص حديث، بيانات مساحة الصك لا تطابق القرار المساحي القائم بغرض البناء، وتريد مبنى تجاري/سكني مختلط. بعد التقديم: الفاحص الفني أعاد الطلب ثلاث مرات بملاحظات إنشائية متصاعدة، والمالك مستعجل لأنه وقّع عقد إيجار مسبق.

التشخيص (الطبقتان): - طبقة الملكية: صك ورثة غير محدث + تفاوت مساحة → يوقف كل شيء: المتطلب 1 غير مستوفى بشكلها الحالي. - طبقة الفنية: دورة ملاحظات متكررة → مؤشر أن التصميم أُعد قبل تثبيت اشتراطات القطعة أو أن دراسة التربة غير كافية للنشاط المختلط.

الخطة (شجرة القرار): 1. تجميد التصميم — أي تكلفة تصميم إضافية الآن تضيع (قاعدة: لا تصميم قبل صك نظيف). 2. مسار الملكية: خدمة 2 (تحديث الصكوك): توثيق الحصص عبر ناجز (سهم الشرطي ⚠️ نطاقه يتحقق هناك)، رفع مساحي جديد لحسم التفاوت (خدمة 8 — مساح مرخص)، صك محدث مطابق للقرار. 3. مسار الفنية المتوازي (بلا رفع): اجتماع تصحيح مع المكتب المصمم: جدول بند-كود لكل ملاحظة؛ التحقق من أن تقرير التربة صالح لاستخدام مختلط وحمل أكبر (إن لا → تكليف مختبر بحفر إضافية 💼). 4. إدارة التوقعات: تقرير حالة للمالك: الجدول الزمني الحقيقي (تحديث الصك ⚠️ حسب وزارة العدل + دورة تصميم جديدة + مراجعتان) وتعديل عقد الإيجار بمرونة إن أمكن — الصدق هنا أرخص من وعد غير قابل للتنفيذ 💼. 5. بعد الصك المحدث: إعادة تقديم حزمة نظيفة → ملاحظة واحدة من الفاحص → اعتماد الأمانة (استخدام مختلط استوجب مراجعة اشتراطات التمييزين ودراسة مرورية للنشاط التجاري — استُوفت قبل الإرسال ✅). 6. الإغلاق: تعاقدات (مشرف + مقاول مصنف ✅) → وثيقة آلياً + سداد قسطها → فاتورة وسداد → رخصة سارية → إشعار الجهات → تسليم وفرص إشراف.

دروس الحالة: (أ) تعثر الطبقتين معاً يُعالج بالتجميد والترتيب: ملكية ثم فنية؛ (ب) التفاوت بين الصك والقرار يُحسم بالرفع المساحي لا بالتقدير؛ (ج) الملاحظات المتكررة غالباً أعراض خلل في مدخلات التصميم (اشتراطات/تربة) لا في الأوراق نفسها.

#5. اختبار الإتقان — 10 أسئلة (6 معرفة + 4 قرار)

درجة النجاح: 8/10 (80%) — راجع المفتاح بعد الحل الكامل فقط.

أسئلة المعرفة (1–6)

س1 (اختيار): ما الذي يجعل رخصة البناء «سارية» يمكن التعامل معها؟ أ) صدورها من الأمانة فقط · ب) سداد رسوم الرخصة فقط · ج) سداد رسوم الرخصة ووثيقة التأمين ضد العيوب الخفية · د) طباعتها من المنصة

س2 (صح/خطأ مع التعليل): وثيقة التأمين ضد العيوب الخفية تُطلب من المالك برفع مستندات لدى شركة التأمين عبر منصة خارجية.

س3 (اختيار): دور الفاحص الفني في هذه الخدمة: أ) يعتمد الرخصة نيابة عن الأمانة · ب) يراجع المخططات المعدة من المكتب المصمم للتأكد من مطابقتها لكود البناء السعودي كجزء من إجراءات وثيقة التأمين · ج) ينفذ الرفع المساحي · د) يوقع التصاميم بدل المهندس

س4 (إكمال): رتب المتطلبات الرسمية التسعة حسب ظهورها الزمني النمطي، مشيراً إلى أي متطلبين لا يجوز قلبهما: (دراسة التربة) — (التصميم الإنشائي) — (صك محدث) — (التعاقدات).

س5 (اختيار): من يختار المكتب المشرف والمقاول داخل المنصة؟ أ) الأمانة · ب) شركة التأمين · ج) المكتب الهندسي المصمم · د) الفاحص الفني

س6 (اختيار): شهادة اعتماد التصاميم تصدر/تُطبع: أ) بعد سداد الرسوم فقط · ب) من المكتب الهندسي المصمم بعد مراجعة الفاحص الفني والأمانة والجهات الخارجية وقبل إصدار الرخصة · ج) بديلاً عن الرخصة · د) من المالك مباشرة

أسئلة القرار (7–10)

س7 (حالة): وصل طلب للفحص الفني ثم عاد بملاحظة: «المسافة بين العمود والحد المجاور تقلق اشتراط التمييز التجاري». من يعالج؟ وبأي مستند؟ وماذا تفعل إن تعارض اشتراط كود البناء مع اشتراط البلدية؟

س8 (حالة): سُددت رسوم الرخصة، وظهرت الرخصة بالحالة «غير سارية» ولا تُطبع. ما الخطوة الفورية؟ ومن المسؤول؟ وما المستندات؟

س9 (حالة): مالك لديه صك قديم بلا تحديث + بناء قائم بلا رخصة على جزء من الأرض. يطلب «رخصة بناء للأرض كلها الآن». ما ترتيب خطة التعامل؟ (اذكر الخدمات المتقاطعة).

س10 (حالة): في مرحلة التعاقدات، المقاول المفضل للمالك غير مصنف في بلدي، والمشرف المختار رفض الإسناد بعد الإشعار. ما القرارين المتوازيين الصحيحين لإنقاذ الجدول دون مخالفة الاشتراطات الرسمية؟

🔑 مفتاح الإجابات — اضغط للعرض قبل الإجابة!

مفتاح الإجابات

ج1: ج) — لا تعتبر الرخصة سارية/قابلة للطباعة إلا بعد سداد رسوم الرخصة ورسوم (قسط) وثيقة التأمين ✅ (نص رسمي من الأسئلة الشائعة). ج2: خطأ — لا يلزم تقديم مستندات ولا طلب من منصة خارجية؛ جميع المستندات تُرسل تلقائياً بالربط الإلكتروني، وشركة التأمين تُشعر برابط السداد ✅ (نص رسمي). ج3: ب) — نص رسمي ✅: مراجعة المخططات المعدة من المكتب المصمم كجزء من إجراءات وثيقة التأمين. ج4: الترتيب النمطي: صك محدث → (قرار مساحي) → دراسة التربة ← ثم التصميم الإنشائي (لا يُقلب ترتيبهما أبداً) → التعاقدات آخر مرحلة قبل التأمين والرسوم ✅. المفتاح: تربة قبل إنشائي. ج5: ج) — المكتب الهندسي المصمم يحدد المشرف ثم المقاول ✅ (نص رسمي، خطوتا 6–7). ج6: ب) — نص رسمي من الأسئلة الشائعة ✅. ج7: يعالجها المكتب الهندسي المصمم (ملاحظات تعود له حصراً ✅) بمستند رد: مخطط معدل يبرهن على مطابقة الاشتراط/بند الكود. عند تعارض الكود مع اشتراط البلدية: استفسار رسمي موحد قبل التعديل، وتوثيق الرد في سجل الملاحظات؛ الحل الأعمى (تعديل مزدوج) يكشف ملاحظة جديدة. ج8: فوري: سداد قسط وثيقة التأمين عبر الرابط الآلي ✅ (القسط من شركة التأمين ⚠️)، المسؤول عن التعقب: المنسق؛ المسؤول عن السداد: المالك/المقاول حسب الاتفاق. المستندات: إيصال السداد + الوثيقة، ثم التحقق من تحول الحالة إلى سارية قبل تسليم المالك. ج9: ترتيب إلزامي: (1) لا رخصة جديدة «للأرض كلها» الآن؛ (2) معالجة بناء قائم بلا رخصة: تقييم → تصحيح وضع مبنى (خدمة 11) وتقرير سلامة (13) عند الحاجة؛ (3) تحديث الصك (خدمة 2) مع مطابقة المساحة؛ (4) قرار مساحي سليم بغرض البناء (خدمة 4) إن لزم؛ (5) عندئذ فقط: مسار إصدار رخصة البناء لهذا الملف. ترتيب آخر = رفض مضمون ومخالفة معلقة. ج10: قراران متوازيان: (أ) المقاول: لا اختيار لمصنف؟ إما تفعيل تسجيل/تصنيف المفضل لدى الوزارة ⚠️ أو اختيار بديل مصنف من قوائم بلدي ✅ — الشرط الرسمي لا يُخترق؛ (ب) المشرف: اختيار بديل من المكتب المصمم فور رفضه. موازاة الحركتين مقبولة (خطوتان متتاليتان في المسار الرسمي لكنهما مستقلتان)، مع إخطار المالك وتحديث الجدول الزمني 💼.

#7. الأثر الزمني النمطي للمشكلات 💼

💼 تقديرات ممارسة تشغيلية للمخطط الزمني (ليست مدداً رسمياً ⚠️) — للتدريب على إدارة توقعات العميل.

المشكلة أثرها الزمني النمطي 💼 وقاية مبكرة
صك غير محدث (1) يوقف البداية كلياً — خدمة 2 بمدتها ⚠️ فحص الصك في الجلسة الأولى دائماً
لا قرار مساحي (2) + أيام إلى أسابيع حسب المسار أ/خدمة 4 ⚠️ فحص قائمة أرقام القرارات قبل العقد
ملاحظات فاحص متكررة (6) + دورة كاملة لكل عودة قائمة الفحص الداخلي (04-Technical §6.5)
جهة خارجية معلقة (8) غير قابل للتحكم — يُدرج بهامش كشف اشتراط النشاط قبل التسعير
سداد دون تأمين (11) + يومان إن اكتُشف فوراً؛ أسابيع إن اكتُشف متأخراً تحقق «سارية» في يوم السداد نفسه ✅
مقاول/مشرف غير متوافق (9/10) + أيام بحث بديل موافقات مسبقة قبل مرحلة التعاقدات

ملخص الحالتين في سطر لكل منهما: ① سلف مكتملة + تصميم مطابق = دورة قصيرة بملاحظات قليلة (نموذج ~شهر 🧪). ② صك متفاوت + ملاحظات متكررة = تجميد، علاج ملكية أولاً، ثم إعادة تقديم نظيفة.

#8. قاموس حالات الطلب كما تظهر في بلدي 💼

💼 صياغات تفسيرية للمكاتب عند المتابعة — الأسماء الرسمية الدقيقة للحالات تتحقق من الواجهة الحالية عند التنفيذ (واجهات بلدي تتطور).

الحالة الظاهرة تفسيرها التشغيلي الفعل
«تم إرسال الطلب إلى المكتب الهندسي» ✅ الطلب وصل للمكتب المصمم ولم يقبل/يعمل بعد تنبيه المكتب
مُسند للفحص الفني بانتظار/تحت مراجعة الفاحص انتظار بدورة متابعة
ملاحظات معادة في زمن معالجة المكتب المصمم إغلاق الملاحظات فوراً
معتمَد من الأمانة/بانتظار التعاقدات شهادة اعتماد التصاميم جاهزة — التعاقدات تنتظر اختيار مشرف+مقاول فوراً
بانتظار وثيقة التأمين/الرسوم السدادات غير مكتملة سداد القسط والفاتورة ✅
صادرة — غير سارية ⚠️ فاتورة مسددة والوثيقة لا سداد القسط ثم تحقق «سارية» ✅
صادرة سارية المخرج النهائي طباعة + أرشفة + تسليم

#9. تصحيح مفاهيم شائعة (للتدريب والفريق)

  1. «الرخصة تصدر بعد السداد» — نصف صحيح: تصدر بعد سداد الرسوم والوثيقة، وتظل غير سارية دون الثانية ✅.
  2. «شهادة اعتماد التصاميم = رخصة» — خطأ: هي مخرج وسيط قبل الرخصة ✅.
  3. «الفاحص الفني يعتمد» — خطأ: هو طبقة مراجعة مستقلة؛ الاعتماد للأمانة ✅.
  4. «المكتب المصمم يختار أي مقاول» — لا: مقاول مصنف إلزاماً رسمياً ✅.
  5. «الرفع المساحي عمل المكتب الهندسي دائماً» — لا: عمل المساح المرخص وفق معايير الجهة؛ للمكتب الدخول عبر الخدمات المساحية المنظمة ✅.
  6. «دراسة التربة إجراء شكلي» — خطأ: أساس التصميم الإنشائي ومتطلب رسمي ✅؛ تأخيرها يعيد الحساب كله.
  7. «ملاحظة الأمانة تعالج بالحديث معها» — لا: تعالج بمستند/مخطط معدل داخل الطلب؛ والخلاف النظامي عبر منصة الاعتراضات الموحدة ✅.
