#0. بطاقة الخدمة السريعة

البند التفصيل
المفهوم تصحيح الوضع النظامي والفني لمبنى قائم أُنشئ دون رخصة أو بتجاوزات عمرانية: عبر إصدار «رخصة تصحيح وضع مبنى قائم» (10494)، أو تعديل المكونات (10484)، أو الإزالة الجزئية/الكلية (10473) ✅
المخرج النهائي رخصة تصحيح وضع مبنى قائم إلكترونية عبر بلدي + إغلاق المخالفة ومطابقة الواقع للرخصة المعتمدة ✅
الزمن الأقصى الرسمي (SLA) 10 أيام عمل لمرحلة الخدمة في بلدي ✅ (node/10931 + اتفاقية مستوى الخدمة)
المتطلبات الحاكمة في بلدي (10494) 1) التعاقد مع مكتب هندسي مصنف · 2) سداد رسوم الخدمة · 3) وجود قرار مساحي لغرض تصحيح وضع مبنى قائم ✅
دور المكتب الهندسي والسلامة رفع واقعي (As-Built) + فحص سلامة إنشائية ومعمارية + مخطط المعالجة + استيفاء اشتراطات الدفاع المدني عبر بوابة سلامة (salamah.998.gov.sa) ✅
الغرامات والرسوم رسوم الرخصة عبر حاسبة بلدي + غرامات المخالفات وفق لائحة الغرامات ولائحة تصنيف مخالفات كود البناء (DownloadAttachment/45) — تُسدد من العميل للجهة مباشرة ✅/⚠️

#1. فهم الخدمة — الأسئلة الاثنا عشر

1.1 ما هي الخدمة؟

عملية متعددة المسارات لإصلاح وضع بناء مخالف (بلا رخصة، أو عكس رخصة، أو عكس الاشتراطات): تشخيص المخالفة وفق لائحة التصنيف ✅، اختيار مسار المعالجة (اعتماد/إزالة/هدم)، تنفيذه عبر قنوات بلدي الرسمية، وإغلاق الملف حتى تختفي آثارها القانونية ⚠️ (آلية الإغلاق تتحقق من كل بلدية).

1.2 الأساس النظامي

  • لائحة الغرامات والجزاءات عن المخالفة البلدية ✅ (موثقة في ../../01-REGULATIONS/Regulations.md).
  • لائحة تصنيف مخالفات كود البناء السعودي ✅ — الرابط الرسمي: https://balady.gov.sa/Services/DownloadAttachment/45 (يصنف المخالفة بمستوياتها).
  • اشتراطات البلدية المحلية ⚠️ (تتفاوت في سماحية المعالجة والزمن).

1.3 الجهات

الجهة دورها في هذه الخدمة
البلدية/الأمانة دراسة طلب التصحيح، تحديد فئة المخالفة والغرامة، اعتماد رخصة التصحيح وإغلاق المخالفة ✅
بلدي (المنصة) خدمة «إصدار رخصة تصحيح وضع مبنى قائم» (10494 / node/10931) + خدمات 10484 و10473 و10498 + منصة الاعتراضات الموحدة ✅
المديرية العامة للدفاع المدني اشتراطات السلامة والوقاية من الحريق عبر https://998.gov.sa/ وبوابة سلامة (salamah.998.gov.sa) وخدمة app-saftyreport ✅
كود البناء السعودي مرجع التصنيف الفني للمخالفات وتقييم المباني القائمة (SBC 901 / SBC 801) ✅
ناجز / السجل العقاري وثيقة الملكية والوكالات (najiz.sa أو rer.sa في المناطق المعلنة) ✅
محامٍ مرخص النزاعات القضائية والتسويات المعقدة 📚

1.4 المنصات

منصة بلدي عبر المسار الرسمي الموحد «إصدار رخصة تصحيح وضع مبنى قائم» (10494) (بشرط استصدار قرار مساحي لغرض تصحيح وضع مبنى قائم أولاً ✅)، أو عبر 10484/10473 حسب تكييف الحالة، مع بوابة سلامة (salamah.998.gov.sa) لمتطلبات الدفاع المدني، وناجز / rer.sa لوثائق الملكية والوكالات ✅.

1.5 المتطلبات الجوهرية

وثيقة ملكية سارية · قرار مساحي لغرض تصحيح وضع مبنى قائم ✅ · التعاقد مع مكتب هندسي مصنف عبر بلدي ✅ · رفع واقعي ومخططات «كما هو على الطبيعة» ومخطط المعالجة · تقرير سلامة فني/إنشائي وملف سلامة الدفاع المدني حسب نوع المبنى · سداد رسوم الخدمة وغرامات المخالفات المقررة ✅.

#4. القواعد الذهبية للخدمة

  1. لا تعالج مخالفة قبل توثيقها — توثيق الحالة الحالية قبل أي هدم/تعديل (يحمي العميل والمكتب).
  2. الغرامة للجهة لا للمكتب — أي تدفق مالي عبر حساب المكتب يفتح مسؤولية مالية 💼.
  3. الأمان يسبق المعالجة — إن ظهر خطر إنشائي، تقرير السلامة (13) والإبلاغ الرسمي قبل أي شيء.
  4. لا وعود بالإغلاق — الإغلاق قرار جهة؛ وعدك: ملف كامل ومتابعة موثقة.
  5. حدود دورك: تشخيص/ملف/تنسيق — الحكم النهائي للبلدية، والنزاع لمحامٍ.
