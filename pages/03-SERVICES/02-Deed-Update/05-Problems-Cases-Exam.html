#1. جدول المشكلات (12 مشكلة — الأعمدة التسعة إلزامية)

# وصف المشكلة السبب الجذري كيف تُكشف الأثر المسؤول عن المعالجة الإجراء المستندات المطلوبة متى التصعيد متى الإيقاف
1 تعارض مساحة بين الصك والقيد/المخطط صك قديم صدر قبل اعتماد مخطط حديث أو قياسات أدق مطابقة ثلاثية (خطوة 5) + استعلام القيد رفض التحديث أو اعتماد مساحة خاطئة تمس البيع والبناء منسق + مساح مرخص جدول «متى يلزم الرفع» — تقرير مساحي أو مستند معتمد قائم تقرير مساح مرخص، قرار مساحي إن وجد عند خلاف القياس مع جهة الاعتماد إذا تبين نزاع حدود قائم → تحويل لخدمة 4/محامٍ
2 بيانات هوية قديمة/اسم غير مطابق للسجل المدني صك صدر ببطاقة قديمة أو اسم مختصر مقارنة الصك بالهوية السارية فشل السحب الإلكتروني في بلدي والبنوك منسق تحديث بيانات المالك عبر ناجز بالهوية السارية هوية سارية، صك عند فشل الجلب برقم الهوية → دعم 1950 ✅ —
3 صك مورّث (باسم متوفى) وفاة المالك دون توزيع فحص اسم المالك مقابل الحالة الاجتماعية تعذر أي تحديث باسم المورّث ورثة + محامٍ عند الحاجة مسار الإرث: حصر ورثة ← توزيع/تنازل ✅ (خدمات SLA) ثم التعامل مع الصك وثيقة حصر ورثة، إقرارات التنازل عند خلاف بين الورثة → محامٍ مرخص فوراً عند دعوى قضائية قائمة — يتوقف التعقيب التقني
4 ملكية مشتركة وشريك غير متعاون غياب إجماع أو توكيل فحص الصك (تعدد أسماء) توقف الطلب في الحقول التي تشترط موافقة ⚠️ منسق (تنسيق) جمع موافقات/وكالات الجميع أو مسار نظامي عبر الوكالة المتعددة الأطراف ✅ (SLA) وكالات موثقة، إقرارات رفض شريك صريح → إشعار كتابي + خيار قانوني خلاف ملكية معلن → إيقاف حتى تسوية
5 رفض الطلب لأسباب توثيقية (مستند ناقص/غير واضح) قائمة مرفقات غير مستوفاة بدقة ملاحظة المدقق في ناجز توقف زمن SLA (لا يشمل النواقص ✅) منسق قراءة الملاحظة نصاً ← استكمال نفس النقاط فقط ← رد موثق المستند المطلوب نصاً ملاحظتان متتاليتان متشابهتان → تواصل 1950 ✅ برقم الطلب —
6 رفض ملاحظة مساحية (خلاف قياس) تقرير المساح غير مطابق لمعايير الجهة أو لا يطابق القيد ملاحظة تدققية تأخير وإعادة عمل ميدانية محتملة مساح مرخص مراجعة التقرير مع المساح، تصويب الطريقة/الإسناد، إعادة التقديم تقرير معدل، بيانات ترخيص اختلاف جوهري متكرر → استشار جهة مساحية أعلى ⚠️ إذا كان الخلاف نزاعاً مع جار → إيقاف وتحويل لخدمة 4
7 رهن على العقار غير مكتشف مسبقاً عدم تشغيل استعلام الرهون قبل التقديم استعلام «الرهون» ✅ (SLA) تعطل التعديل أو اشتراط موافقة الدائن ⚠️ منسق إقفال الحالة: موافقة الراهن/تنسيق بنكي قبل المتابعة استعلام رهن، موافقة الدائن تعنت الدائن → تصعيد للعميل بقرار تجاري —
8 انقسام رأي بين الجهات (بلدي تقبل الصك، العدل يطلبه محدثاً والعكس) اختلاف تعريفات «المحدث» وتوقيت تحديث روابط البيانات تعارض مكتوب بين ردّين رسميين عميل محتار وملف عالق منسق توثيق الردّين نصاً بالتاريخ ← سؤال صريح للعدل عبر 1950 عن متطلب حالتك ← قرار موجه للعميل لقطات الردود، أرقام التذاكر بعد جولتين دون حسم → رفع مكتوب عبر قنوات الشكاوى الرسمية ✅ —
9 إدخال رقم صك لا يُجلب في ناجز صيغة رقم الورقي ≠ صيغة القيد الحديث أو أخطاء إدخال فشل الجلب في الخطوة 7 من المسار إحباط مبكر للعميل منسق تجربة الصيغ الموثقة (رقم الورقي/الإلكتروني/بيانات العقار) ← 1950 عند الفشل المستمر صورة الصك، هوية فشل بعد جولتين → استعلام رسمي ببيانات العقار —
10 وكالة غير كافية النطاق لمعالجة الملاحظات توكيل أُبرم بضيق قبل ظهور الملاحظات رفض النظام لصلاحية المفوض توقف الطلب حتى وكالة جديدة مالك + منسق إصدار وكالة موسعة عبر ناجز ✅ + التحقق منها ✅ وكالة جديدة، تحقق المالك غير متاح (سفر) → وكالة خارجية بمسارها ⚠️ زمن أطول —
11 خطأ مطبعي في الصك المحدث الصادر خطأ إدخال أو اعتماد جزئي المطابقة النهائية (خطوة 23) صك جديد لا يصلح للغرض منسق إعادة الدورة فوراً بطلب تصويب عبر ناجز الصك الخاطئ، تقرير المطابقة تكرار الخطأ من الجهة → شكوى رسمية 1950 ✅ —
12 عميل يطالب بمساحة أكبر بلا سند (زيادة فعلية على أرض غير صكه) اعتقاد شائع أن الرفع «يمنح» مساحة سؤال تشخيصي مبكر + تقرير المساح مطالبة تُرفض وقد تتحول نزاعاً منسق (تصحيح توقع) + محامٍ عند التعنيت توضيح كتابي: التحديث يطابق القيد ولا يمنح أرضاً؛ الزيادة قد تحتاج مساراً نظامياً منفصلاً ⚠️ تقرير مساحي، شرح مكتوب إصرار العميل على مطالبة غير مُثبتة → تنبيه قانوني موثق مطالبة بجيرة ملكية أخرى → إيقاف الخدمة فوراً

#2. شجرة القرار النصية (تتفرع بالسبب — لا حل موحّد)

شجرة أ: تعارض بيانات (مساحة/حدود)

تفاوت مساحة الصك عن القيد/الواقع؟
├─ البيانات الشخصية فقط؟ → نعم → تحديث مباشر (لا رفع)
├─ يوجد قرار مساحي/مخطط معتمد يطابق المطلوب؟ → نعم → أرفقه وتابع
├─ لا مستند معتمد
│   ├─ الواقع مطابق للقيد والصك خاطئ → رفع مساحي موثق → تقديم
│   ├─ الواقع أكبر من الصك والقيد → رفع + تقديم على أساس الأدلة ⚠️ النتيجة قرار جهة
│   └─ خلاف مع جار على الحدود؟ → نعم → أوقف التحديث → قرار مساحي (خدمة 4) → محامٍ عند التعنيت
└─ العقار داخل نطاق السجل العقاري؟ → راجع المسار البديل قبل أي شيء ⚠️

شجرة ب: ملكية مشتركة وغير متعاون

عدد الملاك > 1؟
├─ الجميع متعاون؟ → نعم → وكالات/إقرارات لكل شريك ✅ → تقديم
├─ شريك غائب/غير متفاعل؟
│   ├─ قابِل للتواصل → تذكير مهذب موثق + مهلة 💼 → وكالة متعددة الأطراف ✅
│   └─ غير قابل → إشعار موثق للجميع + خيارات نظامية (وكالة قضائية/مسار قانوني) → محامٍ مرخص
└─ خلاف ملكي معلن؟ → نعم → إيقاف التعقيب التقني → قناة قانونية فقط

شجرة ج: صك مورّث

الصك باسم متوفى؟
├─ وثيقة حصر ورثة صادرة؟ → لا → استخراجها أولاً ✅ (SLA فوري للاستعلام/الإصدار مساره ⚠️)
├─ صادرة
│   ├─ اتفاق الورثة على التوزيع؟ → نعم → توثيق التوزيع/التنازلات ✅ (SLA) → صكوك باسم الورثة → ثم أي تحديث لاحق
│   └─ خلاف؟ → محامٍ مرخص (تفصيل قانوني خارج نطاق المكتب)
└─ هدف العميل «تحديث» فقط دون توزيع؟ → اشرح: لا تحديث باسم المورّث — المسار عبر الإرث ⚠️

شجرة د: رفض لأسباب توثيقية

وصلت ملاحظة/رفض؟
├─ توثيقية (مستند) → استكمل حرفياً → رد موثق بكل نقطة → متابعة
├─ مساحية (خلاف قياس) → مراجعة المساح → تصويب/إعادة رفع
├─ صلاحيات (وكالة) → وكالة موسعة ✅ → متابعة
├─ جوهرية (نوع التعديل غير مقبول بهذه السبيل) →
│   ├─ يوجد بديل نظامي (قرار مساحي/مسار إرث) → حوّل المسار
│   └─ لا بديل واضح → استيضاح 1950 ✅ + شكوى رسمية عند التقصير
└─ غامضة → لا تخمّن: استيضاح مكتوب عبر القنوات الرسمية ✅

شجرة هـ: انقسام رأي بين الجهات

ردّان متعارضان (بلدي ↔ عدل)؟
├─ وثّق الاثنين نصاً وتاريخاً (لقطات)
├─ حدد المتطلب الحاكم لهدف العميل النهائي (بناء؟ بيع؟) — العدل مالك الصك، بلدي مستفيد ✅
├─ اسأل العدل صراحة عن حالة ملفك (1950 برقم الطلب) ✅
├─ انتهِ بالمسار الأقوى نظاماً: صك محدث من العدل يرضي بلدي عملياً 💼 (لأن بلدي يسحب من العدل)
└─ استمر التعارض؟ → شكوى رسمية موثقة + تحديث العميل بالخيارات والزمن ⚠️

#3. الحالة العملية الأولى 🧪: صك 1395هـ ومساحة مطابقة (المسار السلس)

بيانات افتراضية للتدريب.

الملف: عبدالله، صك ورقي 1395هـ، أرض 400 م² في حي عريق، المساحة مطابقة للقيد والمخطط، لكن الاسم مكتوب بصيغة قديمة ورقم هوية مفقود من الصك. الهدف: رخصة بناء عبر بلدي التي طلبت «صكاً إلكترونياً محدثاً».

  1. استقبال وتشخيص (خطوات 1–5): بطاقة تفاوت: بيانات مالك فقط — لا مساحة. لا يلزم رفع مساحي (جدول README §3).
  2. التحقق (خطوة 4): استعلام الصك نشط، لا رهن، لا عمليات معلقة ✅.
  3. اتفاق (8–9): عرض سعر: أتعاب تعقيب فقط 🧪 (لا بند مساحي)؛ وكالة إلكترونية بنطاق التقديم والمتابعة، تحققها ✅.
  4. تجهيز (12–13): هوية سارية بالاسم الرباعي، صورة الصك، بيانات القطعة/المخطط، إقرارات.
  5. تقديم (14–18): دخول ناجز، اختيار الخدمة («تحديث أو تعديل صك عقاري» ✅ اسم SLA)، تعبئة، مرفقات، إقرار، إرسال، رقم طلب ولقطات.
  6. رسوم (19): طلب النظام سداداً — المبلغ كما ظهر في الواجهة ⚠️ (لم يتحقق سلفاً — لا رقم من عندنا).
  7. متابعة (20–21): بعد 6 أيام عمل ملاحظة واحدة: «مطابقة الاسم مع السجل المدني» — رد بإرفاق إفادة المطابقة/إقرار موثق 🧪.
  8. الإغلاق (22–25): اعتماد في اليوم 12 من التقديم (١٠ أيام SLA + استكمال النواخص ✅ متسق)، صك إلكتروني محدث، تحقق عبر «خدمات التحقق» ✅، تسليم، واقتراح الخطوة التالية: قرار مساحي بغرض البناء (خدمة 4) ثم رخصة البناء (1). الدرس: المطابقة الثلاثية المبكرة وفّرت كل التكلفة المساحية، والتوثيق جعل الملاحظة الوحيدة حداً سريعاً.

#4. الحالة العملية الثانية 🧪: صك بمساحة أقل من الواقع (مسار الرفع + الملاحظات)

بيانات افتراضية للتدريب.

الملف: سارة، صك 250 م²، المخطط المعتمد يقول 300 م²، القياس الفعلي 298 م². الهدف: بيع وتمويل — البنك توقف عند تفاوت الصك. لا خلاف جيران.

  1. تشخيص (1–7): تفاوت مساحة حقيقي + لا مستند معتمد لدى العميل → رفع مساحي مطلوب. عقار خارج نطاق السجل العقاري (فحص خطوة 6) ⚠️.
  2. اتفاق (8–9): عرض سعر ببندين: تعقيب + مساحي 🧪، مع بند جولة ملاحظات إضافية. وكالة نطاقها يغطي رفع المرفقات والرد.
  3. ميداني (10): زيارة مساح مجدولة وتأكيد قبل 48 ساعة 💼، قياس GNSS/RTK، تثبيت زوايا، تصوير. لا اعتراض جار.
  4. تقرير (11): مساحة فعلية 298 م² + جدول مقارنة (صك 250 / قيد-مخطط 300 / فعلي 298) + إحداثيات + كروكي + بيانات الترخيص. مراجعة المكتب: مكتمل.
  5. تقديم (12–18): الحزمة: هوية، صك، تقرير، كروكي، إقرار. إرسال ورقم طلب.
  6. ملاحظات (20–21): جولة أولى: «توضيح مصدر مساحة 300 في المخطط» → رد: صورة اعتماد المخطط من جهته + مقارنة الرقمين. جولة ثانية: «إعادة إرسال التقرير بجودة أعلى» → مسح ضوئي أفضل. (الزمن المعلن ١٠ أيام توقف عدّه أثناء النواقص ✅ — أُبلغ العميل مسبقاً).
  7. الإغلاق (22–25): اعتماد بمساحة مطابقة لمعطيات الجهة، صك محدث، تحقق ✅، تسليم، توجيه للبنك: السحب الإلكتروني للصك الجديد 🧪. الدرس: الفرق بين 300 و298 ليس خطأ — التقرير يوثق الواقع، والجهة تعتمد وفق قواعدها؛ وإدارة توقعات العميل حول زمن النواقص أنقذت الثقة.

#5. دورة حياة الملاحظة (من ورودها حتى إغلاقها)

المرحلة الفعل المسؤول زمن داخلي 💼 التوثيق
الالتقاط قراءة نص الملاحظة كاملاً + لقطة + إدخال في سجل الملاحظات منسق فور الورود لقطة + سطر سجل
التصنيف توثيقية / مساحية / صلاحيات / جوهرية / غامضة منسق يوم عمود تصنيف
التوزيع إسناد للمنفذ المناسب (منسق/مساح/محامٍ) منسق يوم اسم المنفذ
التنفيذ إعداد الرد/المستند حرفياً على نقاط الملاحظة المنفذ 1–3 أيام ملف الرد
المراجعة مطابقة الرد مع كل نقطة نصاً (أربع عيون) مراجع قبل الرفع توقيع مراجعة

قاعدة: لا ملاحظة تُرد جزئياً — رد جزئي يعيد الملف من جديد ويحرق مدة أخرى.

#6. قوالب رسائل جاهزة للعميل (تحرير مهني 💼 — تُكيَّف حسب الحالة)

أ. عند ورود ملاحظة:

السلام عليكم — تحديث حالة طلب صككم رقم ____: وردت ملاحظة من وزارة العدل نصها: «____».
التصنيف: توثيقية/مساحية. الإجراء المطلوب: ____. الوقت المتوقع: ____ أيام عمل.
ملاحظة: المدة الرسمية المعلنة (١٠ أيام) لا تشمل زمن استكمال النواقص — لذلك الجدول تحدَّث وفقاً لذلك.

ب. عند تجاوز المدة المعلنة دون حركة:

تجاوز طلبكم المدة المعلنة (١٠ أيام) من تاريخ ____. فتحنا استعلاماً رسمياً برقم الطلب عبر
التواصل العدلي 1950 بتاريخ ____ (رقم التذكرة: ____). سنوافيكم بكل رد فور وروده.

ج. عند تعارض ردود الجهات:

بين أيدينا ردّان رسميان متعارضان (بلدي بتاريخ ____، والعدل بتاريخ ____). المعلومة الحاكمة
لهدفكم النهائي هي مخرَج وزارة العدل لأن بلدي يسحب الصك منها. سنسير على تحديث الصك ثم
نعيد التحقق لدى البنك/بلدي. سجلنا الردّين نصاً للدفاع عن مساركم.

د. عند حالة مورّث (إرث):

الصك باسم المورّث، ولذلك لا تُقدَّم «خدمة تحديث» بهذه الصيغة. المسار الصحيح: وثيقة حصر
ورثة ثم توثيق التوزيع/التنازلات عبر ناجز. عند أي خلاف بين الورثة نحيلكم لمحامٍ مرخص —
هذا خارج صلاحيات المكتب ولا نتدخل فيه.

هـ. عند إيقاف الخدمة (نزاع/مطالبة غير مُثبتة):

أوقفنا العمل على الطلب لسبب موثق: ____. ما يمكن استئنافه فوراً: ____. المسار البديل
المقترح: ____. كنتم أبلغتم بالقرار كتابياً في هذا التاريخ، والملف محفوظ كاملاً لدينا.

#7. سلم التصعيد الداخلي (متى ينتقل الملف لمستوى أعلى)

المستوى الحالة من يقرر

2 ملاحظة مساحية أو تكرار ملاحظة مراجع + مساح مرخص
3 تجاوز مدة معلنة أو تعارض جهات مدير المكتب (قرار تواصل رسمي)

5 شكوى رسمية على الجهة مدير المكتب عبر قنوات الشكاوى ✅

#8. أسئلة يعترض بها العملاء عادة (وإجابة الجاهز)

  • «لماذا يطلبون تحديثاً والصك عندي منذ أربعين سنة؟» → لأن بلدي والبنوك يسحبون الصك إلكترونياً من قاعدة العدل الحديثة، وأي تفاوت يوقف السحب — التحديث يربط صكك بالقيد الحديث.
  • «هل أفقد ملكيتي أو دفعة؟» → لا؛ التحديث لا ينقل الملكية ولا ينشئ ملكية جديدة — هو توحيد بيانات.
  • «جاري يقول إن جزءاً من الأرض له» → هذا نزاع حدود لا يحله تحديث الصك؛ المسار: قرار مساحي (خدمة 4) وقد يلزم محامٍ — والقياس مستقل حتى تُحسم.
  • «كم الرسوم بالضبط؟» → تظهر في ناجز لحظة الطلب ⚠️ — لا نعطي رقماً من خارج المنصة، وسنعرض لك ما يظهر نصاً.
  • «أسرّعوا الطلب مقابل مبلغ إضافي؟» → لا توجد «تسريعة رسمية» نعرفها ⚠️؛ ما نضمنه هو ملف مكتمل من أول مرة ورد فوري على الملاحظات — وهذا هو التسريع الحقيقي.

#9. اختبار الإتقان — 10 أسئلة (6 معرفة + 4 قرار)

معرفة:

  1. ما الاسم الرسمي الموثق لخدمة تحديث الصكوك في اتفاقية مستوى الخدمة لوزارة العدل، وكم مدة تنفيذها المعلنة؟
  2. لماذا تُعتبر هذه الخدمة «بوابة شبه إلزامية» لمعظم الخدمات اللاحقة؟ اذكر المتطلب الرسمي المرتبط.
  3. اذكر ثلاثة فروق جوهرية بين تحديث الصك وفرز الوحدات.
  4. في أي الحالات يلزم رفع مساحي قبل التحديث، وفي أيها لا يلزم؟ (حالتان لكل طرف).
  5. من الجهة التي تعتمد التحديث، ومن الجهة المستفيدة منه التي لا تعتمده؟
  6. ما أثر ملاحظات «استكمال النواقص» على المدة المعلنة ١٠ أيام؟

قرار:

  1. عميل يطلب تحديث صك باسم والده المتوفى. ما تصرفك فوراً؟
  2. صك بمساحة 300 م² والقياس الفعلي 285 م² دون خلاف جيران ولا مستند معتمد. ما المسار الكامل بترتيبه؟
  3. ملاحظة في ناجز غير مفهومة نصاً، والعميل يضغط «أرسل أي شيء». ما تصرفك؟
  4. بلدي يقبل صك العميل والبنك يرفضه لتفاوت المساحة، والعميل محتار. كيف تحسم؟
🔑 مفتاح الإجابات — اضغط للعرض قبل الإجابة!

مفتاح:

  1. «تقديم طلب تحديث أو تعديل صك عقاري» — ١٠ أيام، توافر 24/7 ✅ (SLA وزارة العدل).
  2. لأن بلدي تشترط رسمياً «صك إلكتروني محدث من وزارة العدل» لخدماتها الإنشائية؛ فبدون تحديث تُعطل رخصة البناء وما يليها (فرز/بيع/تمويل).
  3. التحديث لا يغيّر عدد الصكوك ولا المالك وينشئ بديلاً لنفس الصك؛ الفرز ينشئ صكوكاً مستقلة متعددة من صك واحد؛ الفرز قد يشترط اشتراطات بلدية/دفاع مدني/مرافق بينما التحديث لا يشترطها.
  4. يلزم: مطالبة بمساحة فعلية مختلفة، أو خلاف حدود، أو غياب مستند مساحي معتمد للمساحة الصحيحة. لا يلزم: تفاوت بيانات مالك فقط، أو وجود قرار مساحي/مخطط معتمد يثبت المساحة المطلوبة، أو مطابقة تامة.
  5. الاعتماد: وزارة العدل (كاتب العدل/القسم العقاري) عبر ناجز. المستفيدة غير المعتمدة: البلدية عبر بلدي (تشترط المخرج ولا تشارك في اعتماده).
  6. المدة المعلنة لا تشمل زمن استكمال النواقص ولا زمن الجهات الأخرى — فكل ملاحظة توقف العدّ، ولهذا نجدول تقديراً أطول للعميل 💼.
  7. أوقف فوراً فكرة «تحديث» باسم المورّث: لا تحديث لصك مورّث — المسار عبر الإرث (حصر ورثة ← توزيع/تنازل عبر ناجز) ✅، مع إحالة قانونية لمحامٍ مرخص عند أي خلاف بين الورثة.
  8. فحص نطاق السجل العقاري ← رفع مساحي من مساح مرخص (قياس + تقرير بمقارنة رقمية + كروكي + بيانات ترخيص) ← حزمة مستندات ← تقديم عبر ناجز بوكالة موثقة ← سداد الرسوم كما تظهر ⚠️ ← متابعة ومعالجة الملاحظات ← اعتماد وتحقق وتسليم. لا قرار مساحي لغياب نزاع حدود.
  9. لا تُرسل تخميناً: استيضاح نص الملاحظة عبر 1950 ✅، ووثق السؤال والجواب؛ الرد السطحي يثير ملاحظات جديدة ويطيل العدل الزمن.
  10. حدد المصدر الحاكم: الصك يصدر عن العدل وبلدي يسحب منه — فالمسار الأقوى تحديث الصك لدى العدل حتى يرضي البنك وبلدي معاً؛ وثّق ردّي الجهتين، وقدم للعميل مساراً واحداً مكتوباً بدل التردد بينهما.

معيار النجاح: 8/10 (80%) على الأقل. ما دون ذلك: إعادة قراءة README.md §القسم الثالث و03-Executive-Workflow.md قبل التعقيب الفعلي.

#10. أخطاء القرار الخمسة الكارثية (تُعرض في تدريب المنسقين)

الخطأ مظهره ثمنه البديل الصحيح
1 «تحديث» صك مورّث كأنه صك عادي رفض + تضييع أسابيع + لبس قانوني للورثة قناة الإرث أولاً (شجرة ج)
2 قبول رقم مساحة من العميل/جيرانه دون قياس ملاحظة أو اعتماد بيانات خاطئة تدخل وثيقة رسمية رفع معتمد أو مستند قائم (شجرة أ)
3 متابعة قياس على أرض فيها خلاف حدود جارية تقرير يرد عليه المدقق + تصعيد النزاع توقف + خدمة 4 + قانوني عند الحاجة
4 رد جزئي على ملاحظات متعددة دورة جديدة كاملة لكل نقطة مهدرة رد نصي يغطي كل نقطة
5 ذكر رقم رسمي للرسوم من ذاكرة/مصدر غير رسمي خرق القائمة الحمراء + خلاف مالي مع العميل «حسب ناجز وقت السداد ⚠️» فقط

#11. بطاقة جيب للمنسق (قرار سريع في 30 ثانية)

الصك سليم؟ → لا خدمة. الصك باسم مورّث؟ → قناة الإرث + محامٍ عند الخلاف.
تفاوت بيانات مالك فقط؟ → ناجز مباشرة بلا مساحي.
تفاوت مساحة؟ → مستند معتمد قائم؟ لا → مساح مرخص. خلاف حدود؟ → توقف + خدمة 4.
رهن؟ → استعلام ✅ + موافقة دائن ⚠️. ملاك متعددون؟ → موافقات الجميع أولاً.
ملاحظة؟ → تصنيف → رد نصي كامل لا جزئي. غامضة؟ → 1950 ✅ لا تخمين.
تعارض جهات؟ → العدل حاكم لمخرَج الصك؛ بلدي مستفيد. وثّق ثم قرر.
رسوم؟ → من الشاشة فقط ⚠️. وعد زمني؟ → تقديري 💼: ١٠ أيام ✅ + نواقص + جهات.
دائماً: لقطة لكل شاشة، رقم لكل طلب، مستند لكل حقل.
مخرَج ناقص المعاينة؟ → لا تسليم؛ دورة تصويب فورية (خطوة 23).
