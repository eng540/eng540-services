بوابات التوقف (Hold Points): مسار متسلسل يحدد ما الذي يسبق ماذا، ويُمنع تجاوز بوابة قبل استيفاء ما قبلها. المسار الأم المعتمد للانضباط التنفيذي 💼:

تحديث الصك ← كروكي / قرار مساحي ← رخصة بناء ← تأمين وإشراف ← شهادة إشغال ← فرز

لكل خدمة في المصفوفة تأشير جاهزية المسار: ☐ جاهز / ☐ نواقص — ولا يُرفع الطلب قبل أن يكون التأشير «جاهز». مفتاح التأشير: ☐ متوفر / مطابق · ☐ غير متوفر / نواقص · ☐ تم التنفيذ · ☐ لا ينطبق.

#جدول المصفوفة

الخدمة الشرط المسبق الإلزامي (لا تبدأ بدونه) العمليات المتوازية أثناء التنفيذ الخدمة اللاحقة المرتبطة
تحديث الصكوك (02) — عبر ناجز أصل الصك الورقي (وجهين) + الهوية + بيانات القطعة والمخطط. استخراج إفادة بلدية إذا وُجد نقص في الأطوال أو الحدود. القرار المساحي (04) أو التسجيل العيني (12).
التسجيل العيني الأول (12) — عبر السجل العقاري RER صك إلكتروني محدث + وقوع العقار بمنطقة عقارية معلنة. مطابقة الرفع الجيومكاني وحدود العقار في خريطة RER. الصحيفة العقارية والفرز العيني.
الكروكي المساحي (08) صك ملكية واضح الحدود + رفع ميداني لأركان الأرض (GNSS). ربط الإحداثيات بشبكة SANSRS ومطابقة المخطط. القرار المساحي (04) أو التجزئة (09).
القرار المساحي (04) — بلدي صك إلكتروني سارٍ + تفويض المكتب ببلدي + رفع مساحي. تدقيق الارتدادات والشوارع والشطفات واعتماد البلدية. رخصة البناء (01) أو الترميم (05) أو الهدم (10).
تقسيم ودمج الأراضي (09) — بلدي / إتمام صك إلكتروني + قرار مساحي + الحد الأدنى للمساحة والواجهة. اعتماد كروكي التجزئة/الضم وإحالته لكتابة العدل. تحديث الصكوك الجديدة (02) ثم رخص البناء (01).
رخصة البناء (01) — بلدي قرار مساحي سارٍ + عقد تصميم + فحص تربة + مخططات الكود (SBC). حساب الرسوم البلدية (14) وحصر الكميات وسداد الفاتورة. التأمين + عقد الإشراف على البناء + إشعار البدء.
الإشراف على البناء — عملية مكتبية عبر بلدي رخصة بناء سارية + عقد إشراف + عقد مقاول + وثيقة التأمين. استلام مراحل البناء ميدانيًا ورفع تقارير بلدي والتأمين. إصدار شهادة الإشغال (06) وإطلاق التيار.
شهادة الإشغال (06) — بلدي معاينة الواجهات والرصيف وسداد الدفاع المدني (للتجاري). اكتمال تقارير مراحل الإشراف + رسم الشهادة (200 ريال ⚠️). إطلاق الكهرباء، الفرز (03)، أو رخصة النشاط.
تقرير سلامة المبنى (13) — SBC 901 معاينة ميدانية للمبنى القائم + فحص خرسانة مختبري + واقع حال. تقييم العمر الافتراضي والسلامة الإنشائية ومتطلبات الحريق. تصحيح وضع قائم (11) أو رخصة ترميم (05).
تصحيح وضع مبنى قائم (11) — بلدي قرار مساحي + مخططات واقع حال + تقرير سلامة + دفاع مدني. دراسة لجنة مخالفات البناء بالأمانة وسداد الغرامات والرسوم. شهادة الإشغال للمبنى المصحح وفرز وحداته (03).
فرز الوحدات العقارية (03) — REGA صك إلكتروني + رخصة بناء/تصحيح + مخطط فرز بطبقات CAD. تحليل الأجزاء المشتركة ونسبها وسداد الرسوم (100 ريال/وحدة ⚠️). إصدار صكوك مستقلة للوحدات وجمعية المالك.
رخصة الترميم (05) ورخصة الهدم (10) قرار مساحي/رخصة + تقرير SBC 901 (ترميم) أو فصل مرافق (هدم). تعاقد مكتب مشرف ومقاول وتوفير حاوية نفايات وتأمين الموقع. شهادة إتمام الهدم أو إغلاق أعمال الترميم.

ثانيًا: القواعد الذهبية العشر للتحقق والتأشير (ملخص الانضباط التنفيذي بالمكتب الهندسي) 💼

  1. الصك الإلكتروني أولًا: لا تبدأ أي إجراء بلدي أو مساحي قبل التأشير على سريان الصك الإلكتروني وخلوه من النواقص في ناجز أو RER.
  2. التتالي الإلزامي للخدمات: التزم بتتابع الخدمات (تحديث صك ← كروكي/قرار مساحي ← رخصة بناء ← تأمين وإشراف ← شهادة إشغال ← فرز).
  3. مطابقة الطبيعة قبل التصميم: لا تصمم على أبعاد الصك نظريًا قبل التحقق من الرفع المساحي الميداني المربوط بشبكة SANSRS.
  4. الصرامة في كود البناء (SBC): تحقق من الارتدادات، نسبة البناء، المواقف، والعزل الحراري والمائي قبل رفع المخططات.
  5. المختبرات المعتمدة شريك إلزامي: لا تصدر رخصة بناء بدون فحص تربة، ولا تصدر تقرير سلامة مبنى قائم (SBC 901) بدون فحص خرسانة.
  6. صيغ وطبقات الملفات (DWG/PDF): راجع انغلاق المضلعات وتسمية الطبقات قبل رفعها لمحرك الفرز الآلي أو منصة بلدي لتفادي الرفض الآلي.
  7. متطلبات ما بعد الرخصة: نَبِّه المالك كتابيًا بأن رخصة البناء تتطلب (تأمين العيوب الخفية + عقد إشراف + مقاول مصنف) قبل الحفر.
  8. فصل المرافق قبل الهدم: يُحظر التصريح بالهدم قبل التأشير على خطابي فصل الكهرباء (933 ✅) والمياه وتأمين المباني الملصقة.
  9. بوابة الجودة النهائية (النموذج 8): راجع كل حرف ورقم في الوثيقة الصادرة (الاسم، الهوية، القطعة، المساحة) قبل تسليمها للعميل.
  10. التوثيق والأرشفة الرقمية: احفظ قائمة التحقق المؤشرة مع إيصالات السداد والمخططات النهائية في مجلد المعاملة المرقم بالمكتب.
