#1. الموقف

يوم الأحد 10:30 صباحاً، اتصال هاتفي:

«السلام عليكم، أنا محمد بن عبدالله العتيبي. عندي أرض في الرياض ورثتها عن أبي، أريد أبني فيها فيلا للسكن. صديقي قال احتاج رخصة بناء فقط. كم تكلفتها ومتى تصدر؟»

البيانات الأولية الملتقطة (نموذج الاستقبال ../07-TEMPLATES/01-Client-Intake-Form.md): | الحقل | القيمة | |---|---| | العميل | محمد بن عبدالله العتيبي — 10xxxxxxxx — مواطن | | العقار | أرض فراغ، الرياض، حي النرجس (🧪)، «مخطط لا أذكر رقمه» | | الصك | «صك قديم ورقي من زمن أبي» — غير محدث | | الحاجة المعلنة | «رخصة بناء فقط» |

⚠️ لحظة تعليمية 1: العميل طلب «رخصة بناء فقط»، لكن متطلب رسمي موثق ✅ (بلدي): رخصة البناء تشترط صكاً إلكترونياً محدثاً وقراراً مساحياً بغرض البناء ودراسة تربة وتعاقدات (مصمم/مشرف/مقاول مصنف) وتأميناً ضد العيوب الخفية. «الرخصة فقط» وصف غير صحيح للعمل — التشخيص الصحيح: حزمة سلسلة بناء كاملة.

#2. موعد الفحص والتشخيص (خطوات 1–7 من الـ25)

بعد يومين: استلم العميل المستندات، وأجرينا الفحص الوثائقي (نموذج ../07-TEMPLATES/02-Property-Inspection-Form.md):

البند النتيجة الأثر
الصك ورقي قديم باسم الوالد المتوفى ❌ مساران: إثبات ملكية/توزيع إرث عبر ناجز (قد يحتاج محامياً عند التعقيد) ثم تحديث الصك (خدمة 2) — وهذه بوابة إلزامية قبل أي شيء
رقم القطعة/المخطط مذكور ✅ (قطعة 12، مخطط النرجس) يسهل جلب الاشتراطات
مساحة الصك 600م² ✅
ملكية مشتركة؟ لا (بعد توزيع الإرث ستصبح فردية — افترضت 🧪) لو كانت مشتركة: موافقات الجميع
مخالفات؟ لا شيء معروف نتحقق لاحقاً

⚠️ لحظة تعليمية 2: توقف العمل هنا. لا سعر ولا وعد قبل حسم مسار الملكية. قاعدة التشغيل (../05-OPERATIONS/Workflow/Transaction-Operations-Guide.md §6): اكتشاف عدم اكتمال الملكية = تعديل النطاق قبل التعاقد.

#3. عرض السعر (خطوة 8) — بنية الحزمة

وفق منهجية ../05-OPERATIONS/Pricing/Pricing-Guide.md:

البند كيف حُسب
أ. توزيع إرث + تحديث صك (تعقيب عبر ناجز) أتعاب تعقيب 💼 — الرسوم الرسمية ⚠️ من ناجز
ب. قرار مساحي بغرض البناء أتعاب مساح مرخص 💼 + رسوم بلدية ⚠️ (حاسبة الرسوم)
ج. دراسة تربة عرض مختبر 💼
د. مكتب هندسي مصمم عقد مباشر 💼 (حسب التصنيف والمساحة)
هـ. مكتب مشرف عقد مباشر 💼
و. مقاول مصنف + وثيقة تأمين العيوب الخفية يتعاقد العميل مع المقاول؛ التأمين عبر شركة التأمين آلياً ✅
ز. رسوم الرخصة حاسبة الرسوم البلدية ⚠️ — لا رقم مختلق
ح. أتعاب التعقيب (رفع بلدي أعمال + متابعة + ملاحظات) ساعات محسوبة 💼 + VAT 15% 📚

سُلّم العرض بخطين: «ما تسدده أنت مباشرة» و«ما نعقّبه لك» — وقاعدة السداد: دفعة بدء 40% 💼، وتسديد الرسوم الحكومية من العميل مباشرة عبر روابط السداد الرسمية.

#4. التنفيذ (خطوات 9–20) — التسلسل الرسمي الموثق ✅

  1. تسوية الملكية: طلب إثبات ملكية/توزيع إرث عبر ناجز (تعقيب) → ثم تحديث الصك (خدمة 2) → صك إلكتروني محدث باسم العميل. (المدة: تقديرية 💼 — لا وعد رسمي).
  2. القرار المساحي بغرض البناء (خدمة 4): إسناد مساح مرخص → رفع ميداني بـ RTK → تقرير مساحي → الطلب عبر بلدي (خدمات التقارير المساحية ✅) → صدور القرار.
  3. التفويض البلدي الإلكتروني ✅: العميل يفوّض المكتب الهندسي المصمم من بلدي.
  4. المكتب المصمم (في بلدي أعمال): يقبل التفويض → يبدأ الطلب → يختار التقرير المساحي للأرض ✅ → يعد التصاميم وفق SBC واشتراطات القطعة → يرفق ويوافق على التعهدات → يرسل الطلب لشركة الفحص الفني.
  5. الفحص الفني: مراجعة مطابقة كود البناء ✅ → (في حالتنا 🧪 جاءت 3 ملاحظات: ميل سلم، نقص تفصيل عزل، مواقف) → عادت للمكتب → معالجة خلال 5 أيام 💼 → إعادة → قبول.
  6. اعتماد الأمانة → شهادة اعتماد التصاميم ✅.
  7. مرحلة التعاقدات: اختيار المكتب المشرف (يوافق) → اختيار مقاول مصنف (يوافق ويعبئ بياناته) ✅.
  8. التأمين ضد العيوب الخفية: صدر طلبها آلياً ✅ → المقاول سدد روابطها ✅.
  9. رسوم الرخصة: فاتورة بلدي → سداد العميل ✅ → إصدار الرخصة (تذكير: غير سارية قبل سداد التأمين ✅).
  10. الإشعارات: بلدي أشعر آلياً الكهرباء والمياه والطاقة والدفاع المدني والتأمين والسجل العيني ✅.

#5. ما بعد الرخصة (الخطوات 21–25)

  • تسليم العميل: نسخة الرخصة + شهادة اعتماد التصاميم + شروح خطواته القادمة (بدء تنفيذ مع مقاول، والتزام المكتب المشرف بإشعارات البناء ✅ — وهي شرط الإشغال لاحقاً).
  • أرشفة: الملف الكامل برقمه في 01-مستندات…07-مالية (قواعد ../05-OPERATIONS/Workflow/… §1).
  • متابعة العميل: أرسلنا تذكيراً مجدولاً عند بدء كل مرحلة تنفيذ، وفتحنا فرصتين: شهادة الإشغال (خدمة 6) عند الاكتمال، وفرز الوحدات (خدمة 3) إن أنشأ شقتين.
  • تقييم الرضا (نموذج 08): 🧪 9/10 — نقطة التحسين: لو أوضحنا مسار الإرث في أول اتصال، لاختصرنا أسبوعاً.
