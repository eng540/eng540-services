#1. المراحل الثماني (لكل خدمة)

المرحلة ماذا تفعل فيه ملفات المرجع بوابة النجاح
1. الفهم اقرأ README الخدمة وأعد الشرح بأسلوبك 03-SERVICES/*/README.md شرح بلا خطأ جوهري
2. الأنظمة والجهات احفظ خريطة الجهات الست والأساس النظامي README §الجهات + 01-REGULATIONS/ اختبار جهات 10/10
3. المنصات امش المسار داخل المنصة (محاكاة) 03-SERVICES/*/01-Platform-Steps.md + 02-PLATFORMS/ مسار كامل بلا طريق مسدود
4. الإجراءات تعقب الخطوات الـ25 ومنفذ كل خطوة 03-SERVICES/*/03-Executive-Workflow.md ترتيب صحيح لحالة معطاة
5. تحليل التنفيذ اقرأ الحالة العملية وحلل القرارات 03-SERVICES/*/05-Problems-Cases-Exam.md 5 قرارات مؤثرة محددة
6. المحاكاة الكاملة نفّذ حالة من الاستقبال للتسليم 08-TRAINING/Simulations/ + النماذج ملف معاملة مكتمل
7. الحالة الاستثنائية عالج ملاحظة/رفض/تعارض عبر شجرة القرار نفس ملف المشكلات + 07-TEMPLATES/06 حل بالمسار الصحيح + توثيق
8. اختبار الإتقان امتحن 08-TRAINING/Exams/ + اختبار الخدمة ≥ 80% + قرارات صحيحة

#2. طريقة الاستخدام (للمتعلم الذاتي أو المدرب)

  1. اختر خدمة واحدة فقط في البداية — التوصية: ابدأ بـ«رخصة البناء» (أم الخدمات).
  2. ابنِ «سجل إتقان» شخصياً: صف لكل مرحلة بتاريخ الإتمام ودرجتها.
  3. في المحاكاة استخدم بيانات افتراضية كاملة (لا بيانات حقيقية) — راعِ أن تملأ النماذج فعلياً من 07-TEMPLATES/.
  4. بعد كل خدمة ثلاث: أعد اختبار الخدمات السابقة (تثبيت).
